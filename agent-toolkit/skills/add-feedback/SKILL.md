# 通常型フィードバックの対話投入

利用者向け要件を協調モードの対話で確定し、計画を作成せず通常型フィードバックとして投入する。
要求本文の完成前に利用者向け結果を確定し、後続の自律処理へ判断を残さない。

## 手順

1. `agent-toolkit:process-feedbacks`の`## フィードバック投入`節を全文読む。
   共通投入手順の参照だけを目的とし、同スキル自体は起動しない
2. フィードバック本文から未確定の選択肢、確認要求、実装時へ残した判断事項を抽出する
3. 技術調査または明文化済み方針で確定できる事項は自ら確定する。
   内部実装だけの判断は利用者向け要求本文へ固定せず、未確定事項としても残さない
4. 利用者向け結果に影響する選好は現在の対話で確認し、回答を得てから本文を確定する。
   協調モードの確認をTBDへ置き換えず、回答前に通常型フィードバックを投入しない
5. 共通投入手順に従って対象リポジトリ、重複、実装済み状態を確認する。
   共有作業ツリーの変化だけを理由に、完了した調査や投入準備をやり直さない
6. `--plan-file`を指定せず`atk mq add`を実行し、通常型として投入する。
   登録後は保存されたメタデータと本文を再取得して照合する

## 完成条件

- 利用者向け結果に影響する未確定事項が本文へ残っていない
- 技術判断と内部実装の判断が利用者の選好として問い直されていない
- `plan_file`を持たない通常型フィードバックとして登録されている
- 登録後に取得した本文が確定済みの要求と一致している
