# 振り返りの判断基準

通常・batchのメインの問題選別と原因・対策確定に使う。
手順・入出力は本体、分析・投入は`session-analysis.md`、非同期の対象固定・範囲は`batch.md`、報告は読込表の`report-formats.md`が定める。
複数対象でも同じ基準を使い、対象IDと記録位置を保持する。
