# セッション振り返り

自動batchは、同じOSアカウントでadd-awi-by-userを起動した会話が開いている間は見送る。
入力待ちと登録完了後も含め、最後の該当会話が閉じた後のSessionStart・SessionEndで既存条件を再評価する。
手動の振り返りと手動batchは従来どおり利用でき、実行中の振り返りは中断しない。

個別の原因・対策へ進む前に次を確認する。

- 会話の流れを通読し、既存の判断・行動への是正要求、新しい要望、通常回答を区別して、各要求の扱いを記録する。
- 案内や基準の存在、本文の取得、実際の適用、処置の効果を分けて確かめる。
- 既起票の要求が扱う範囲、実装・配布の状況、適用機会と今回の結果を比較し、解消した範囲を判定する。
- 同じ害の反復と未取得の証拠を保持し、可能な追加取得を済ませてから未確定範囲と処置を引き渡す。

最初に引数の先頭語を確認し、次の表から1つの処理資料を全文読む。
先頭語がbatchと完全一致する場合だけbatchモードとし、その語を除いた残りを追加の着眼点として保持する。
先頭の空白と語の区切りには空白・タブ・改行を使える。
一致しない場合と引数なしは通常モードとし、引数全体を着眼点として扱う。
着眼点の文頭にbatchという語を置く場合は、別の語から書き始める。
`batch auto`のautoも着眼点であり、自動起動の判別は起動元の情報で行う。
着眼点に対象を限定せず、選んだ資料が指定する対象全体を振り返る。
共通分析は各モードの準備後に読み、通常モードのprepareとbatchの準備済み範囲を重複処理しない。
CI履歴の継続改善も、各モードの共通分析で扱う。
