# plan-file-creator起動プロンプトの必須見出し

`agent-toolkit:plan-mode`手順3が`plan-file-creator`を起動する際、および
`agent-toolkit-edit`等の他スキルが同エージェントを起動する際の起動プロンプトが満たす形式を定める。
`agent-toolkit/scripts/pretooluse.py`のPreToolUse検査が本ファイルの4見出しの実在と直下本文の
非空を機械検査し、欠落時はAgent/Task起動をブロックする。

## 必須見出し

起動プロンプト本文へ次の4つのH2見出しを、この表記のまま含める。各見出し直下に非空の本文を置く。

| 見出し | 記載内容 |
| --- | --- |
| `## 計画ファイルパス` | 新規作成時は`~/.claude/plans/{stem}-{rand}.md`（`{rand}`は`openssl rand -hex 2`の実行結果である16進4桁。`plan-file-creator.md`「入力」節・`plan-mode/SKILL.md`「計画ファイル（本ファイル）のパス」節と同一の命名規約。`noclobber`による確保結果を含む）、改訂時は既存パス |
| `## permission_mode` | `plan`または非`plan` |
| `## 合意済み事項` | `## 背景`・`### ユーザー合意済み事項`・`### エージェント判断`・`### 却下した代替案`・`### 恒久化・リファクタリング内容`へ転記する材料 |
| `## 照合結果` | 呼び出し元が起動前に実施した、ユーザー発話・提示素材との照合結果 |

見出しの実在と非空のみが機械検査対象であり、内容の妥当性（合意済み事項が実際にユーザー確認を
経ているか等）は呼び出し元自身の調査完遂責務（`01-agent.md`「調査と検証」節）に委ねる。

## 追加情報

「必須見出し」節の4見出しに加え、対象ファイル一覧・実施範囲・実施済みレビュー結果の転記など
`plan-file-creator.md`「入力」節が定める他の材料は、任意の見出し・書式で追記してよい。
