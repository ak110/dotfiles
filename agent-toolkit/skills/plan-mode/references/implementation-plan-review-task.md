# 計画準拠の実装差分レビュータスク

最終commitの差分が承認済み計画と一致するかを読み取り専用で検査する。成果物を修正しない。

## 入力

- 計画ファイル、対象worktree、プロジェクト規範、`agent-toolkit:review-standards`の絶対パス
- 計画着手前SHA、レビュー対象commit、変更ファイル一覧、検証結果、進捗ログの現在状態
- 初回または再レビューの別。再レビュー時は採用指摘と修正結果

入力が欠ける場合は推測せず、欠落項目を返す。

## レビュー

- 計画の`## 目的`、`## 対応方針`、実装者向け領域、`### 対象ファイル一覧`、
  `## 進捗ログ`の現在状態を差分と実体へ照合する
- 計画に規定のない実装詳細を新しい義務として要求しない
- 計画からの逸脱、実装漏れ、許容されていない挙動変化、生成・配布経路の追随漏れだけを指摘する
- 境界条件と回帰は独立系が担うため、本系統の指摘として重複させない
- 指摘ごとに違反する計画項目と、実行結果または実装箇所の裏付けを示す
- 裏付けられない候補は`未検証`として指摘と分ける
- 対象worktreeと計画ファイルを変更しない。起動前後のGit状態を報告する

## 出力

対象commit、点検範囲、`write_status: unchanged`を返す。
実在する指摘には`P-<通番>`、重大度、箇所、違反する計画項目、内容、根拠、修正方針を含める。
指摘がない場合は`指摘なし`と明記する。
