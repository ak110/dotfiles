# grilling

`agent-toolkit:plan-mode`又は`agent-toolkit:plan-and-add-awi`の直接起動で、実装前に必要な共通理解へ到達するためのユーザー確認手順。
`agent-toolkit:process-wi`経路では本書を適用せず、確認事項をUWIへ登録する。

## 確認対象

ユーザーとエージェントの責任分担と確認要否の判定は`agent-toolkit/rules/01-agent.md`「協調と自律」を正本とする。
計画の変更対象又は採用方針を左右する未確定判断を、判断同士の依存関係とともに列挙し、同節の判定でユーザーの選好に依存すると確定した判断だけを確認対象とする。
環境上の事実、既存コード、利用可能なツール、ライブラリ仕様など自分で調査できる事項はユーザーへ尋ねない。

## 質問ラウンド

未回答の判断へ依存しない確認対象を同じラウンドへまとめて提示し、回答のたびに依存関係を更新する。
別の未回答判断へ答えが依存する確認対象は後のラウンドへ回す。
調査の完了待ちで確認全体を止めず、その調査結果を必要とする質問だけを保留する。

## 質問表示

`AskUserQuestion`のようなユーザー確認ツールが利用でき、次の固定テンプレートが持つ質問番号、質問タイトル、質問本文及び推奨回答を表現できる場合は当該ツールを使う。
利用できない場合は次の固定テンプレートに従う。
書式が固定されないと、ユーザーは質問の位置・推奨案・回答単位を毎回読み直すことになり、読解負担と見落としが増えるため、自由形式へ置き換えない。

````text
❓ **Q1** - **<質問タイトル>**: <質問本文。複数段落や複数の選択肢を含んでもよい>

➡️ <あなたの推奨回答>

---

❓ **Q2** - **<質問タイトル>**: <質問本文。複数段落や複数の選択肢を含んでもよい>

➡️ <あなたの推奨回答>
````

質問を提示したら、そのラウンドの回答を待ってから次のラウンドへ進む。

## 終了条件

未回答のユーザー判断と、その判断を妨げる未調査の事実がなくなった時点で確認を終了する。

## 終了時報告

質問せずに自分で決めた事項のうち、別の合理的な実装者なら異なる判断をし得るものを、ユーザーが異論を持つ可能性が高い順に一度報告する。

````text
- **決定**: <エージェントが選んだ内容>
  - **理由**: <なぜそれを選んだか>
  - **最有力の対案**: <選ばなかった中で最も有力だった案>
````

この報告は承認を求めるものではないため、追加承認を待たず計画ファイル初版の起草へ進む。
ユーザーが後から異論を示した場合は、その判断と依存する後続判断を更新する。
