# 別セッションとの共有資源の申し送り

直接連絡できない別セッションと同じ資源を使う担当が、作業の重複や引き継ぎの取り違えを防ぐための手順である。

- 申し送りが必要になった時だけ、双方が利用を合意した認可済みの既存の運用記録を使う。
  一方だけが場所を知っている、相手が読む合意がない、または保存の認可がない場合は記録を作らず、必要な調整をユーザーへ引き継ぐ。
- 宛先・伝える事項・期限を所有者ごとの別の短い記録に書く。
  所有者だけが自分の記録を更新し、不要になったら自分の記録だけを回収する。
- 共有資源を操作する担当は、操作の前に合意した場所の申し送りを読む。
  閲覧できることを送達や排他の保証とみなさず、操作の認可と書き込みの所有権は別に確かめる。

この記録を、届かなかった指示の再送、新しい連絡場所の設置、外部への投稿には使わない。
