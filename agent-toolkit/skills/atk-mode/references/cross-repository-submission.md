# 複数リポジトリへの投入

本書は、複数のリポジトリへ投入するAWI、同じ成果の整合性を求める複数のAWI、上流リポジトリの改訂が必要な要求、別リポジトリへ移管する元項目の扱いを定める。

## 独立したAWIへの分割と依存

1. 各リポジトリの現行の状態を確かめ、自身の管理対象だけで実施・完成判定できる個別のAWIへ分割する。
   各AWIの冒頭には目的と変更の要点を、本文にはリポジトリ固有の反映先・差分・完成状態を書く。
2. 共通の要求・原因分析・調査結果・判断根拠・ユーザーの逐語引用は、代表となるAWI1件へ集約する。
   他のAWIには、代表AWIの正式ファイル名、`target_repo`、参照する節や項目と、自リポジトリ固有の条件を書く。
   代表AWI自身の作業も、自リポジトリだけで完了できるようにする。
3. 共通本文を読むエージェントは、採否・計画・実装・レビューの判断の前に、代表AWIの指定箇所とユーザーコメント・回答を`atk wi show <正式ファイル名> --target-repo=<代表AWIのtarget_repo>`で取得し、固有の本文と合わせて有効な要求を確定する。
   終了済みの代表AWIも読む。
   参照先の終了状態と、本文を読む必要性は分けて扱う。
4. 各リポジトリの現物の確認と採否は個別に行い、自リポジトリの反映内容に限って要求を確定する。
   `depends_on`は後述の先行成果が必要な場合に設定し、説明の共有、整合性の維持、投入の順序は本文の参照で扱う。
5. 保存は代表AWIを先に行い、確定した正式名を他のAWIへ反映する。
   代表AWIを移管する場合は参照元も更新する。
   参照先に届かない時は、保存結果・移管先から取得を回復してから、共通の要求を含む処理を再開する。
6. 後続のAWIの実施に先行成果が必要な場合は、待つべき先行成果と、先行成果が無いと成立しない工程や完成条件を後続の本文へ書く。
   そのうえで、先行AWIを登録して得たファイル名を後続の`depends_on`に指定する。
   依存関係は後続から先行への一方向だけとし、先行AWIの完成条件から後続の着手や完了を除く。
7. 複数のリポジトリにまたがって不可分で、単一の計画と単一の検証でだけ成立する変更に限り、1つの計画へ集約する。

## 上流リポジトリへの投入と元項目

1. 対象リポジトリ単独では実装できず上流リポジトリの改訂が必要な要求は、元項目を移管せず、上流リポジトリへ新規AWIとして投入したうえで元項目を保持する。
   投入する本文には、要求内容、対象リポジトリの識別子、上流の改訂後に対象リポジトリ側で実施する作業内容（作業が無い場合は、上流の成果の確認だけが残る旨）を書く。
2. 上流への投入が完了した後は、元項目の依存関係を新たに投入したAWIのファイル名で更新する（維持すべき既存の依存関係も同じ実行で指定する）。
   元項目の状態が`processing`であれば`inbox`へ戻し、`blocked_reason=dependency-unmet-external`が設定されることを確かめる。
3. 先行項目や上流項目が未終了でも、元項目を保留する前にその`完成条件`が満たされているかを、対象リポジトリの現行HEADと成果物から確かめる。
   確かめた条件、HEADの7文字以上の短縮OID、判定結果を記録に残す。
   条件を満たしていれば、現在の状態にかかわらず依存関係を解除し、`--commit`を省略して終了処理を行う（`agent-toolkit:atk-mode/references/states-and-dependencies.md`「状態遷移」）。
   条件の充足を確かめられなければ、実装済みと推定せず、依存先、未達の条件、再開条件を明記して保留する。
4. 上流項目の終了後は、対象リポジトリ側の残作業を実施するか、上流の成果を確かめて元項目を終了する。

## 元項目の移管

1. 元項目そのものを別リポジトリへ移管する場合は、WIの投入の手順（`agent-toolkit:atk-mode/playbooks/wi-saving.md`「投入」）で、frontmatterと本文を含む全体を、正しい`target_repo`を指定して登録する。
   更新するキーは予約キーの`target_repo`だけとし、`alert_keys`などの非予約キーと`source`の値はそのまま保つ（通常の`atk wi add`は、frontmatter内の`target_repo`をCLI引数の値で自動では置き換えない）。
2. 登録の成功を確かめた後に限り、移管先のリポジトリ名とファイル名を除去理由として記録したうえで、元の項目を除去する。
