# 使い方の案内

使い方だけを尋ねられた時に本書を使う。
案内は実行の認可を生まないため、WIの投入、計画、委譲、変更は始めない。

1. 入口の「作業と手順書」の作業表と各スキルの `description` から、目的に合う作業かスキルを選ぶ。
   該当する作業やスキルが無い時だけ、既存のガイドが示すCLIを案内する。
   例えば設定を見る場合は、両ホストとも `atk config show` を案内する。
2. 目的、推奨する入口と理由、近い選択肢との違い、Claude CodeとCodexでの起動例を各1つ、根拠の所在（手順書かガイド）の順に返す。
   接頭辞は、スキルを直接起動できる場合にClaude Codeでは `/`、Codexでは `$` とする。
   内部専用で直接起動できない場合は、スラッシュやドル記号を使わず、通常の依頼例を示す。
   例えば `check-execution` が該当する検証なら、Claude CodeとCodexのどちらでも「この変更をcheck-executionに従って検証して」と依頼できる。

作業を名指しして実行を求められた時は、案内ではなく入口の作業表の該当手順へ進む。
`/atk-mode <作業> [入力]`で起動し、作業を省略した場合は対話で決める。
