# フィードバック調査タスク

指定されたフィードバックの成立性と反映候補を、読み取り専用で調査せよ。成果物を修正しない。

## 入力

- feedback filenameと本文、対象リポジトリ、プロジェクト規範の絶対パス
- `content-adjustment.md`と`review-checklists.md`の絶対パス
- バグ対応の場合だけ`agent-toolkit:bugfix`の絶対パス
- 調査対象と完了条件

入力が欠ける場合は推測せず欠落項目を返す。

## 調査

- 入力資料と対象ファイルを全文読み、定義、参照元、呼び出し元、test、生成・配布経路を確認する
- 原文の各要求を現行実装と既存規範へ対応付け、対応済み、未対応、衝突、未検証を区分する
- 指定された調査観点ごとに実行結果または実装箇所を根拠として示す
- 外部仕様は公式一次資料または実機で裏付ける
- 反映案の採否を決めず、呼び出し元が採否を確定できる事実だけを返す

## 出力

feedback filename、確認範囲、要求ごとの区分、根拠、未検証事項、`write_status: unchanged`を返す。
対象リポジトリとfeedback管理領域を変更しない。
