# 外部サービスへの投稿前レビュー

本スキルは投稿後に第三者へ届く文面を、起草者と独立した読み取り専用の担当が投稿前に検証する手順を提供する。
投稿する主体が対象の判定、レビューの依頼、指摘の採否及び投稿を担う。
投稿操作の認可は`agent-toolkit:confirmation-and-uwi`に従って判定する。

## 対象と入力

第三者が読む外部サービスへエージェントが起草又は加筆した人間向け文面を対象とする。
ユーザーが逐語で渡した文面、git push、コミットメッセージ及びprivate-notesのWI本文は対象外とする。
git pushとコミットメッセージは`agent-toolkit:commit`、WI本文は`${CLAUDE_PLUGIN_ROOT}/share/wi-draft-review.parent.md`の契約に従う。

投稿する主体は確定した文面をUTF-8のファイルへ保存する。
投稿先と投稿の目的、文面が根拠とする差分・観測結果・関連ファイルの所在を対応付ける。
レビュー担当へは、文面ファイルの絶対パスと行数、投稿先と目的、根拠の所在、読者像及び後述の観点を渡す。
読者像はそのセッションの文脈を持たない第三者とする。
レビュー入力から規範ファイルを除く。

## 起動と受領

投稿する主体は、`agents_server`の読み取り専用`start_explore`でレビュー担当を起動する。
`fast`は既定値の`true`を用いる。
委譲先として投稿する主体も、同じ担当内の独立した確認を読み取り専用の子探索へ分ける。

レビュー担当には、文脈を持たない読者が目的と変更理由を理解できるか、文面の事実主張が渡した根拠と一致するかを確認させる。
あわせて、AWI・UWIのファイル名、セッション識別子、手元だけのパスなどの内部識別子と秘匿値の混入、及び`agent-toolkit:writing-standards`「人間向け文章の共通規定」が求めるPR・MR説明の粒度を確認させる。
結果は`atk agents wait --output-file <絶対パス>`で保存して受け取り、起動したsessionの終端を確認する。
投稿する主体は`agent-toolkit:review-standards`の`references/reviewee.md`に従って指摘の採否を確定し、採用した指摘を文面へ反映してから投稿する。
レビューは投稿前に1回実施し、反映後の再レビューを自動で繰り返さない。

起動した`start_explore`のsessionが結果を返さずに終端した場合は、同じ入力で1回だけ起動し直す。
再度結果を得られない場合は、次の手段不在と同じ扱いにする。
`start_explore`を起動できず、同等の読み取り専用の委譲手段も利用できない場合は投稿を止める。
協調モードでは文面と阻害条件をユーザーへ報告し、自律モードでは`agent-toolkit:wi-standards`に従って事前承認型UWIへ送る。
