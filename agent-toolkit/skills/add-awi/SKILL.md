# AWI投入

本スキルは、ユーザーが手動起動したエージェントワークアイテム（AWI）を登録する入口である。
本スキルを起動したセッションで許される成果物の編集は、WIの登録と更新に限る。
対象リポジトリの実装、実装を目的とするworktreeの作成、AWIの`processing`への移動、実装担当の起動へ進まない。
起動後に受領する「反映して」「修正して」その他の反映を求める発話は、AWI本文への反映を求める指示として解釈する。
対象リポジトリの実装を求める指示へ読み替えず、実装の可否をユーザーへ問う分岐も設けない。
再発防止、完遂その他の要求も、AWI本文への反映として果たす。
登録に必要な一時入力の作成と、管理CLIによる後始末は本項の対象にしない。
共通の許容性の判断は`agent-toolkit/rules/01-agent.md`の「判断指針」と「完遂と先送り」を正本とし、同じ禁止の全文を本書へ複製しない。

## 手順

1. `agent-toolkit:wi-standards`を起動する。本文の起草前に`agent-toolkit:writing-standards`をSkill機能で起動する。該当する本文形式、投入及び保存照合の契約を適用する。
2. 計画実装型の`plan_file`を保存する場合、新規計画は`$(atk config get private_notes)/plans/`から始まるportable値を使い、実在確認・構造検査など実体が必要な時だけ共通resolverで絶対パスへ解決する。
   既存計画に残る旧root又は絶対パスは読み書き互換として受理する。
3. 調査に着手する前に要求の母集団を確定する。母集団は、ユーザー発話の範囲語（「それ以外の項目も可能な限り」「〜全般」「〜の戻り値やパラメーター」など）が指す集合から求め、発話が提示した観測事象そのものを母集団と同一視しない。範囲語と例示が併存する場合の優先順位は`agent-toolkit/share/rules-main.md`「ユーザー発話の解釈」、具体化を要する軸の列挙は`agent-toolkit/rules/01-agent.md`「協調と自律」末尾を正本とし、当該条文を本書へ複製しない。確定した母集団と各要素の調査結果はAWI本文へ残す。主題だけを受け取った通常AWIは、確定した母集団の各要素について、適用規範、対象全文、定義・参照・呼び出し元、関連テスト、生成・配布経路及び履歴を調査する。技術主張を実装、実行結果又は公式一次資料で裏付け、ユーザー依存事項を対話で確定する。
4. 規範又は設定の現行記述について欠陥、誤り若しくは誤解釈を主張する場合だけ、`git log -S`で導入変更を特定し、`atk config show`が示す`private_notes`配下の対応する採用済み項目とユーザー追記を確認する。
5. `agent-toolkit:wi-standards`の投入手順が定める判定で、変更する定義を所有するリポジトリを対象リポジトリとして確定する。当該リポジトリの正確なローカルworktreeが既知なら、その絶対パスを対象リポジトリとして使う。利用できるローカルworktreeがない場合だけURLを使い、worktreeを推測しない。
6. `agent-toolkit/skills/plan-mode/references/grilling.md`を全文読み、同書に従って質問ラウンドを繰り返す。ユーザーの選好に依存する未確定判断が無くなった時点で確認を終え、同書の終了時報告を出力する。
7. `atk wi add`を実行する前に、保存する本文の全文をユーザーへ提示し、投入の可否の回答を得る。全文はフェンス付きコードブロックで囲まず地の文へそのまま出力し、`--body-file`へ渡す本文ファイルの絶対パスを`AskUserQuestion`の質問本文へ書く。ユーザーが修正を求めた場合は本文を改訂し、同じ提示と確認を繰り返す。
8. `agent-toolkit:wi-standards`の投入手順で保存結果を検収する。警告、エラー又は保存内容の欠落があれば完了扱いにせず、同じ経路で修復する。
9. 手順8の検収が完了した後、メインが完成済みのAWI投入結果を作業固有の成果として渡して`agent-toolkit:completion-report`をSkill機能で起動し、ユーザー向け完了報告を生成する。

本スキルは協調モードで動作する。`agent-toolkit:wi-standards`の「投入と取得」が協調モードの投入へ求める投入前の調査と確定は、本スキルを起動したセッションで完了する。

本スキルが投入する項目の`source`は`add-awi`とする。この値は投入したスキルの名前であり、由来の判定において人間由来を意味しない。ユーザーが本セッションで発した要求は、原文を改変せず本文中へ出所を示し、`agent-toolkit:writing-standards`の「ユーザー入力素材の取扱い」が定める逐語引用の記法で引用する。`## ユーザーコメント`の見出しを作成しない。当該見出しはユーザー自身が記入する欄であり、エージェントによる引用と区別する。引用の外へ書いた範囲はエージェント由来として扱う。

## セッション境界

冒頭が定める成果物の限定は、完了報告後も同一主題が続く限り維持する。文脈の復帰後も同じ扱いとする。
同一主題への追加指示か別主題かを判別できない場合は、投入前にユーザーへ確認する。
計画の作成を明示的に求められていない場合は、計画工程を開始しない。
委譲先を起動する場合は、起動したスキル、許容する成果物の種別、当該セッションの終端を起動文へ含める。

## 完成条件

- ユーザー向け結果に影響する未確定事項が通常AWIへ残っておらず、ユーザーの選好に依存する事項の回答を投入前に得ている
- 保存する本文の全文をコードブロックで囲まずに提示し、投入の可否の回答を得てから`atk wi add`を実行している
- 通常AWIの技術主張と、該当する場合の原因分析及び決定記録を確認済みである
- 通常AWIの`完成条件`が、実装方式に依存しない外部可視の終了状態と操作の要否を一意に示している
- 保存された本文とmetadataが入力に一致し、警告又はエラー後の再取得でも欠落がない
- processing項目を変更していない
