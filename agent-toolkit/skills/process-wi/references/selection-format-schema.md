# 選定YAMLの項目と省略規則：選定結果の書式

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

## 選定結果の書式

生成付き保存操作の出力は以下の形式となる。
既存の完成済み選定YAMLを受け取る場合も同じ形式に従う。
保存前には生成入力の意味判断として、`選定`の各項目における上流投入関連の3行について省略時の値を解決し、以下の組み合わせに合致していることを確認する。

| `上流投入`の解決値 | `レーン` | 担当 |
| --- | --- | --- |
| `なし`（行の省略を含む） | 通常の`lane-NN` | ファイル変更の有無を問わず、レーン担当が採否・実施・終了を担う |
| `上流要求だけ` | `なし` | メインエージェントが既存の上流投入工程を実施する |
| `混在` | 通常の`lane-NN` | メインエージェントが上流投入した後、対象リポジトリ側の作業をレーン担当へ引き渡す |

この条件は、作業を伴う回答済みUWIにも適用する。
ファイルの変更を伴わない項目であっても待機状態にせず通常レーンへ割り当てる。
その際、レーンへの割り当て自体は外部操作の承認を意味しないものとして扱う。
`上流投入`が`なし`以外の場合、`上流投入先`には1件以上の空でない文字列のリストを、`上流要求`には空でない文字列を指定する。
`なし`の場合は3行とも省略する。

```yaml
選定:
- WI: '<AWIまたは作業を求める回答が保存されたUWIのファイル名>'
  レーン: '<`lane-NN`形式のレーン識別子(`NN`は2桁のレーン番号)または「なし」>'
  鮮度: <`atk wi list --with-staleness`が返した`staleness`のYAMLフロー写像>
  書込対象: ['<書込対象のリポジトリ相対パス>']
  導出した新設先:  # 省略時の値: 「[]」
  - パス: '<限定調査で導いた完全な新設ファイルの相対パス>'
    反映範囲: '<対応する実在ディレクトリ範囲、末尾/付き>'
    要求: '<同じWIの新設を求める要求>'
    配置根拠: '<読んだ既存の定義・接続先と配置理由>'
  公開工程の書込対象: ['<全レーン統合後の公開工程だけが書くリポジトリ相対パス>']  # 省略時の値: 「[]」
  公開工程の規範根拠:  # 省略時の値: 「[]」
  - パス: '<公開工程の書込対象のパス>'
    規範ファイル: '<公開工程へ割り当てる規範のリポジトリ相対パス>'
    節: '<規範ファイルの見出し文字列>'
  担当モデル: {実装担当: '<engine:model/effort>', 実行レビュー担当: '<engine:model/effort>'}
  書き込まない反映先: ['<反映先としてWI本文に現れるが書き込まないリポジトリ相対パス>']  # 省略時の値: 「[]」
  再開位置: '<`~/.claude/plans`内の計画ファイルの絶対パスと残る工程。観測のみの書式は「反映後の観測だけが残る（再開記録: AWI本文の最後の`## 反映後の観測の再開記録`、計画: <`private-notes/plans/`からの相対パス|計画なし>）」>'  # 省略時の値: 「なし」
  プロジェクト固有の公開後の操作の順序: '<プロジェクト固有の公開後の操作とその順序>'  # 省略時の値: 「既定」
  プロジェクト規範の指定: '<プロジェクト規範が指定した内容>'  # 省略時の値: 「なし」
  上流投入: '<上流要求だけまたは混在>'  # 省略時の値: 「なし」
  上流投入先: ['<投入先>']  # 省略時の値: 「なし」
  上流要求: '<上流要求と対象側の後続作業>'  # 省略時の値: 「なし」
  統合状態: '<未統合|統合済み>'  # 省略時の値: 「未統合」
単一段階案の完了見込み秒数: <bool以外の0以上の数値>  # 段階2以上がない場合は省略可、省略時の値: 「なし」
段階案の完了見込み秒数: <bool以外の0以上の数値、または「成立する段階案なし」>  # 必須条件以外は省略可、省略時の値: 「なし」
目標超過時の配分比較: '<比べた配分の代替案と見込み、採った案>'  # 目標所要秒数を超えない場合は省略可、省略時の値: 「なし」
全工程の見込み:  # 目標を持つ実行配分で省略すると警告になる（拒否はしない）。旧保存形式の履歴では省略時「未確認」
  並列数:
    モデル同時数: <正の整数>
    資源上限: <測定した資源から成立すると確認した正の整数>
    サービス上限: <API・CLIで利用可能な正の整数>
    根拠: {資源: '<実測の参照>', サービス: '<制限の参照>', 費用: '<同品質の候補間の総費用比較の参照>'}
  工程:
  - ID: '<群と工程を区別するID>'
    工程: '<選定|準備|実装|レビュー|検証|統合|公開|後始末|報告>'
    WI: ['<この仕事が扱うWI。全体固定工程は[]>']
    先行工程: ['<先行成果を使う工程のID>']
    資源: '<モデル|検証|直列>'
    秒数: <0以上の有限数、未確認はnull>
    算定: '<実測|残量/速度|条件付き試算|未確認>'
    根拠: '<観測または残量と速度の出所>'
    未確認前提: []
    # 算定が残量/速度の場合だけ、残量と正の速度を追加する
  巨大WI:  # 省略時[]。指定しないWIは通常対象に残る
  - WI: '<意味判断の所有者が巨大と判定した具体的WI>'
    巨大判定根拠: '<合理的な資源・費用上限と最短案の比較の参照>'
    承認元: {対象WI: '<同じWI>', 判断: '<承認|拒否|未回答>', 出所: '<今回の名指しの承認原文の所在>'}
見込みの補正:
  実装係数: <bool以外の0より大きい有限数>
  統合係数: <bool以外の0より大きい有限数>
  共有待ち秒数: <bool以外の0以上の有限数>
  共有待ちの算定: '<実測|推定>'
  参照した記録: ['<進捗ログか引き継ぎ記録の所在>']
  除外した記録:
  - 記録: '<除外した記録の所在>'
    理由: '<除外理由>'
初回配分:
  候補WI: ['<開始時候補から通常の除外条件に当たるものを除いた全WI名。包含項目を含む>']
  レーン割当: {'<初回に選定したWI名>': '<初回レーンまたはなし>'}
  不可分成分:
  - WI: ['<成分の構成WI名>']
    結合条件: []  # 複数WIの成分では後掲の型付きの辺を列挙する
追加WI: ['<初回確定後に追加したWI名>']  # 省略時の値: 「[]」
レーンの所要時間:
- レーン: '<`lane-NN`形式のレーン識別子>'
  統合状態: '<未統合|統合済み>'  # 省略時の値: 「未統合」
  段階: <1以上の整数>  # 省略時の値: 「1」
  先行レーン: ['<このレーンのworktree作成前に統合を終える前段のレーン識別子>']  # 省略時の値: 「[]」
  実装秒数: <0以上の数値>
  統合秒数: <0以上の数値>
  補正前の実装秒数: <bool以外の0以上の数値>
  補正前の統合秒数: <bool以外の0以上の数値>
  根拠: '<同一レーン案と分割案の比較根拠を示す空でない文字列>'
レーン間の重なり:  # 省略時の値: 「[]」
- レーン1: '<レーン識別子>'
  レーン2: '<別のレーン識別子>'
  共通パス: '<共通ファイルまたは狭い方の範囲>'
  レーン1の定義: ['<変更する節または定義>']
  レーン2の定義: ['<変更する節または定義>']
  判定: '<交わる|交わらない>'
続行できない理由:
- '<確認事項>'  # 完了時の値: 「なし」
```

文字列の値は書式例のように単一引用符（`'`）で囲み、文字列内の`'`は`''`とエスケープして重ねる。
`[1m]`や`[`、`,`、コロンと空白の連続を含む文字列を引用符で囲まないと、YAMLの構文として誤認されるためである。
`鮮度`のマップや数値は引用符で囲まずに記述する。

候補が0件の場合は、`選定`および`レーンの所要時間`を空のリスト（`[]`）とし、`初回配分`も`候補WI: []`、`レーン割当: {}`、`不可分成分: []`とする。
`追加WI`や、`選定`の各項目ならびに各レーン行の`統合状態`は、省略時の値と一致していれば省略可能であり、行が存在しない場合はそれぞれ空のリスト、未統合として解釈する。

行末のコメントに省略時の値を記載した行は、その値と一致する場合に省略できる。
行が存在しない場合はその省略時の値として読み取る。
`選定`の各項目で必須となる行は`WI`、`レーン`、`鮮度`、`書込対象`である。
`担当モデル`には、WI本文で担当とモデルが明示されている組み合わせのみを、推論の深さを含めた`engine:model/effort`の形式で記録し、指定のない担当のキーは省略する。
`鮮度`には、一覧JSONの`staleness`マップを値や型を変更せずにそのまま転記する。
