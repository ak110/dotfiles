# 選定YAMLの項目と省略規則：見込みの補正の算出

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

## 見込みの補正の算出

計画の`## 進捗ログ`、または計画ファイルを持たないレーンの対象AWI本文に保存された予測補正記録から、対象リポジトリ、選定元、レーン、完了時刻を突き合わせて、実行とレーンの対応関係を確定する。
実装・統合の実仕事の秒数を工程ごとに集計し、対応する補正前の予測秒数の合計で割って`実装係数`・`統合係数`を求める。
共有資源の待ちは実仕事の係数から分離する。

補正前の予測値が欠けている記録、対象工程の予測合計が0秒の記録、対応関係や工程別区間が不明な記録は理由を添えて除外する。
工程別係数の算出には、工程別区間と対応する予測値を持つ記録を使う。
同一の実行・レーン内に複数の計画やAWIが存在する場合は1件として扱う。
有効な工程別記録がなければ過去の実行へ遡り、それでもなければその工程の係数を1とする。
記録には保存済みの進捗ログとAWI本文を使用する。

各レーンに`補正前の実装秒数`と`補正前の統合秒数`を記録し、最上位の`見込みの補正`に工程別係数、`共有待ち秒数`、参照した記録、除外した記録とその理由を記録する。
`実装秒数`と`統合秒数`には対応する工程係数を掛けた数値を設定する。
共有待ちの根拠はレーンの`根拠`へ対応付け、未計測と待ちなしの実測を区別する。
過去の記録から待ちを測れない場合は、`共有待ちの算定`を`推定`とし、共有の検証枠と統合の順番から見積もった0より大きい秒数を使う。
6000秒の判定および段階案との比較にも補正後の数値を用いる。
旧方式の局所比較では共有待ちを1回加え、全工程の成立証拠とは分離する。
全工程の入力・単位と巨大WIの承認境界の定義は`selection-format-fields.md`「全工程と通常対象の算定」とする。
`全工程の見込み`の処理秒数は実測または残量/速度から得た見込みを入力し、同じ係数と共有待ちを除いた仕事の処理秒数として扱う。
モデル仕事・共有2検証枠・直列処理を、先行成果と資源の制約を保って重ねる。
選定・公開・後始末・報告の未測定はnullと未確認前提のまま保持する。
条件付き試算や未確認の前提が残る見込みは数値が目標内でも未成立であり、`pick-wi-check`は警告で示す（拒否しない）。
型の不正などの形式不備は警告ではなく終了コード2になる。
`目標超過時の配分比較`は代替案の記録で、通常対象の超過の警告はその記載の有無にかかわらず出る。
追加候補も既存と同じ工程別係数で補正し、既存レーンへ合流する場合は補正前の2つの数値を累積してから対応する工程係数を掛ける。
合流後の全工程の入力は追加側で再確定し、固定工程と共有待ちをそれぞれ1回だけ計上する。

全件の壁時計見込みと承認済み巨大WIを除いた通常対象の見込みは、同じ依存入力から別々に求める。
通常対象は当該WIだけに属する仕事を除いて再計算し、並行した通常仕事や共通工程を保持する。
共通工程と通常仕事を保持して依存と容量から再計算する。
承認なし・拒否・別WIの承認は有効な除外として扱わず、承認の原文の意味は担当が検収する。

## 予測補正記録

統合工程の進捗ログと、計画を持たないレーンの対象AWI本文に保存する。
書式は`予測補正記録: 対象リポジトリ=<識別子>; 選定元=<出力先の絶対パス>; レーン=<識別子>; 完了時刻=<時差付き時刻>; 補正前実装秒=<秒数>; 補正前統合秒=<秒数>; 補正係数=<係数>; 総経過秒=<秒数>`とする。
選定元は1回のprocess-wi実行を一意に識別する。
補正前の2値は選定結果の`レーンの所要時間`の`補正前の実装秒数`と`補正前の統合秒数`から、係数は最上位の`見込みの補正`の`係数`から取る。
追加のWIがある場合はレーンの累積予測値を使う。
補正前の欄には事前の予測値と確認できた値だけを書き、復元できない過去の記録は不明として次回の集計分母から外す。
同じレーンの複数の計画と、同じ実行・レーンの記録を持つ複数のAWIは、同じ値で1件と数える。
セッション内の引き継ぎ記録には保存先を書く。

工程別の補正を持つ選定では、書式の`補正係数`を`実装係数`・`統合係数`・`共有待ち見込み秒`へ置き換え、対応する選定値を記録する。
実装側の計画・実装・検証本体・レビューと修正、統合の処理、共有実行枠と統合許可の待ちを、進捗ログの開始・終了とコマンド・レビュー記録へ対応付ける。
工程別の実測秒と根拠の所在も同じ記録へ添え、並行する区間は重なりを除いて数える。
区間を確定できない工程は不明とし、その総経過から工程係数を推定しない。
旧形式の総経過・単一係数の保存記録は未分離の履歴として読み、工程別の実測へ流用しない。
