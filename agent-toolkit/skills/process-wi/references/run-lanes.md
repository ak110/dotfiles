# レーンの実行

メインエージェントが確定した対象WIの集合を、選定結果に示されたレーン割り当てと依存順序に従って実行する。
各レーンでは同一の担当スレッドが、必要に応じた計画の起草、実装、レビュー指摘の修正、コミット履歴の統合、およびメイン作業ツリーへの統合を担当する。

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

| 時点または条件 | 全文読む資料 |
| --- | --- |
| 変更したエージェント向け文書を再取得する時 | `../../../share/exec.parent.md` |
| 変更したエージェント向け文書を再取得する時 | `../../../share/exec.parent.md`、`../../../share/exec-parent-integration.md` |

## メインが読む対象の境界

1. メインは選定時にAWI・UWI原文を読み、選定後は構造化出力、計画の`## 概要`・`## 実施内容`、工程境界の出力、レビュー指摘管理表の状態、統合結果を主に読む。
   他節や実装差分はエスカレーション、ユーザー対応、レビュー収束、メイン自身の調査・修正に必要な時に読む。
   レーン・レビュー担当の判断を同じ本文から再構成しない（努力目標。判断の重複を防ぐ）。
   `変更したエージェント向け文書`の再取得は`../../../share/exec.parent.md`、`../../../share/exec-parent-integration.md`に従う。

2. 処理対象WIに含めた理由、除外した理由、または選定の構成についてユーザーから質問を受けた場合は、`selection-procedure.md`の読込表に示された説明手順を参照する。
   該当する説明手順は`${CLAUDE_PLUGIN_ROOT}/skills/process-wi/references/selection-explanation.md`に定められており、メインエージェントは保存済みの選定結果と判断内容に基づいて、その根拠と適用限界をユーザーへ説明する。
