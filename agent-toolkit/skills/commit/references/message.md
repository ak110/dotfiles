# コミットメッセージ

コミットメッセージの件名、形式、type、description、本文と`Co-Authored-By:`の規約を定める。
本書の方針は`.gitmessage`と配布範囲が異なるため意図的に重複させる。
コミットメッセージ第1行は「件名」と呼ぶ。

プロジェクト方針が無ければConventional Commits形式で書き、固定文言体系（カテゴリ名・固定件名等）が指定されていればそれに従う。
プロジェクト方針は`CLAUDE.md`・`AGENTS.md`・`.claude/rules/`、コミットテンプレート、lint設定など実在する明文化された情報から確認する。明文化されていない事項は、同種の複数コミットで一貫して観測され明文の方針と矛盾しない形式だけを慣例として採り、単発の履歴は根拠から除く。方針と履歴が矛盾する場合は`agent-toolkit:review-standards`の`review-standards/references/judgment-details.md`「矛盾の原因調査」に従う。

- 形式: `<type>[(<scope>)]: <description>`。破壊的変更は`!`を付ける。本文かtrailerを持つ場合は件名の後に空行を1行置く
- typeと`!`は成果物の消費主体（配布先のエンドユーザー・開発者・エージェント）の振る舞いへの影響で選ぶ。機能追加・修正・性能は`feat`/`fix`/`perf`、振る舞いに直接影響しない内部変更は`chore`/`ci`/`refactor`/`docs`/`test`とする。lint/format設定・CI手順・依存グループ入れ替えなど開発者向け設定の変更は`!`の対象外とする
- エージェント向け文書は配布先の振る舞いを構成するため、判断分岐、規範削除、機能的な規範変更は`chore`の対象外とする。振る舞いを変えるなら`fix`、変えない構成の整理は`refactor`とする
- scopeは単一モジュール・機能に閉じる場合だけ短い名詞で付ける（努力目標）
- descriptionは日本語で、変更内容より必要性・可能になること・防ぐ問題を先に、scopeが無くても対象を特定できる粒度で書く（努力目標）。エンドユーザーが呼び出す・設定する・目にする識別子は原表記を保ち、言い換えるのは知り得ない内部識別子に限る
- 本文は任意で、書く場合は`agent-toolkit:writing-standards`の`references/writing.md`「人間向け文章の共通規定」に従う

## `Co-Authored-By:`

値はユーザーの明示指示、明文化されたプロジェクト方針、実行環境が提示する帰属の指定の順に確かめ、最初に観測できた定義で決める。空文字列の指定は帰属の明示的な無効化とする。
いずれにも定義が無い場合は`Co-Authored-By: <実行中のモデルの表示名> <noreply@<モデル提供元のドメイン>>`を付ける（Codexのドメインは`openai.com`）。
入れるモデルと推論量（effort）は、commitを実行するturnのホスト記録から観測した値とし、モデル設定・alias・起動候補の値は起動用の値として扱う。観測できた場合だけtrailerを付ける。
最終コミットメッセージへ1回だけ付け、既存の異なるtrailerは保持する。

- Claude Codeは帰属の指定の`{model}`と`{effort}`を置き換えずに渡すため、エージェントが値を得て書く。推論量はBashで`printenv CLAUDE_EFFORT`を実行して得る。モデルはホストが通知するモデルIDから末尾の角括弧の印（`[1m]`など）を除いた値とする（PreToolUseが期待値を求める記録の`message.model`は印を持たないため）。`claude-<系列>-<主版>-<副版>`（末尾に8桁の日付が付く場合を含む）は`Claude <系列の先頭大文字> <主版>.<副版>`へ変換し、形の合わないIDはそのまま使う。推論量は先頭を大文字にする（例: `Co-Authored-By: Claude Opus 5.5 / Medium <noreply@anthropic.com>`）
- Codexでは本書をシェルで読み取ると、PreToolUseの追加コンテキストが読取時点に観測したモデルと推論量の帰属行を届ける。観測できない場合は推測せず、commitするturnのホスト記録を確認する
- 読取時点の観測は後で変わり得るため、commit直前にも現在のモデルと推論量を確かめる。期待値と異なる行、不正な行、重複行はPreToolUseが遮断し、通知が正しい帰属行を示すので、その行で実行し直す
