# Web画面の実装とレビューで確認する規則

本書は、HTML、CSS、JavaScriptでエンドユーザー向け画面を実装又はレビューする主体が、コードから判定できる条件を扱う。利用者の操作で生じる結果は`ui-ux.md`の実描画確認でも確かめる。

主な参考資料: [Vercel Web Interface Guidelinesの取得時点の原文](https://github.com/vercel-labs/web-interface-guidelines/blob/e3d624baaf29dc1fc645aff3e38f03e564d2d6b1/command.md)（commit `e3d624baaf29dc1fc645aff3e38f03e564d2d6b1`）。原文を実行時に再取得せず、本書の規則を判定へ使う。英語の文章表記に固有の規則は日本語画面の判定対象から外す。

## アクセシビリティとフォーカス

- 操作には`button`、遷移には`a`を使い、キーボードと新しいタブでの利用を保つ。アイコンだけのボタンへ名前を付け、装飾アイコンを支援技術から隠す。意味のある画像へ代替テキストを付ける。
- 入力欄へ関連付いたラベルを置く。見出しを階層順に置き、本文へ移動するスキップリンクを用意する。非同期通知と入力検証の結果を適切なlive regionで伝える。
- キーボードで到達する操作に`:focus-visible`の視認可能な表示を用意する。`outline: none`を使う場合は同等以上の代替を同じ状態へ置く。固定ヘッダー、フッター、オーバーレイの下でもフォーカス中の要素を視認できる位置へ保つ。

## フォーム

- 入力の目的に合う`name`、`autocomplete`、`type`及び`inputmode`を指定する。ラベルのクリックで対応する欄へ移れる構造とし、貼り付けを利用できるようにする。
- 送信開始前の送信ボタンは利用可能に保ち、送信中は進行を示す。入力エラーは該当欄の近くに表示し、送信時は最初のエラーへフォーカスを移す。
- 入力値の変更が失われる画面離脱では警告又は保存の選択を用意する。ブラウザーの戻る操作、ダイアログを閉じる操作も同じ損失として扱う。

## 内容、状態、遷移

- 長い文字列は折り返し、適切な省略と全文への到達手段を選ぶ。flexの子へ必要な`min-width: 0`を設定し、空文字列や空配列でも表示を保つ。
- フィルター、タブ、ページ番号、展開状態など、再訪や戻る操作で復元すべき状態をURLへ反映する。破壊的操作には確認又は取り消し猶予を置く。
- エラーには原因と次の操作を示し、閉じたオーバーレイはキーボードフォーカスの対象から外す。

## 動き、画像、性能

- 動かすCSSプロパティーは可能な範囲で`transform`と`opacity`へ限定し、`transition: all`を避ける。動きはユーザー操作で中断でき、`prefers-reduced-motion`で装飾的な動きを止める。
- 画像へ`width`と`height`を指定して表示領域を予約する。初期表示より下にある画像は遅延読込を検討する。画面へすぐ必要な画像は優先して読み込む。
- 50件を超える一覧では仮想化又は`content-visibility`などで描画量を抑える。描画の途中でレイアウト読取とDOM書込を交互に行わず、読取と書込をまとめる。

## テーマと地域化

- ダークテーマを提供する場合は`color-scheme: dark`を設定し、ネイティブ`select`の背景と文字の色を指定する。ダークテーマの新設は、その画面の要求に応じて判断する。
- 日付と数値は`Intl.DateTimeFormat`と`Intl.NumberFormat`で地域に応じて整形する。翻訳対象でないブランド名、コード片、識別子には`translate="no"`を用いる。
- Reactなどでサーバー側描画とhydrateを使う場合は、入力値の変更ハンドラーと、日時の描画結果が両側で一致する条件を確認する。

## 避ける実装

画面拡大を妨げる`user-scalable=no`と`maximum-scale=1`、貼り付けの阻止、代替のないフォーカス枠の除去、操作できると誤認する非操作要素、寸法のない画像、ラベルのない入力欄、無名のアイコンボタンを検出した場合は、利用シナリオへの影響を確認して修正する。
