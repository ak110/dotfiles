# 秘匿値ファイルの取り扱い

本書は`agent-toolkit/rules/02-agent-operations.md`「ツール・コマンド運用」が委ねる、秘匿値を含むファイルの読取と書換の制約の正本である。
秘匿値ファイルを扱う時に全文読む。

秘匿値を含むファイル（`.env`、`.env.<接尾辞>`、鍵、証明書などの、値の秘匿を前提とするファイル）は、
必要なキーの値だけを取り出す操作に限って読む。当該ファイルの全文の読み取り、出力及び複製を禁止する。
同一リポジトリのworktreeへ実行前提ファイルを複製する操作は、本項の対象にしない。
`agent-toolkit:delegation`の`references/mandatory-rules.md`が、当該操作を認証情報の再配置の禁止対象から除いているためである
（厳守規定。全文がログ、トランスクリプト、生成物などへ複写されると秘匿値が露出する）。

動作確認のために`.env`及び`.env.<接尾辞>`の値を追記、変更又は削除する操作は、
Bashの追記（`echo ... >>`）又は`sed -i`で行う。編集ツールによる同ファイルの書き換えは行わない。
鍵、証明書などの他の秘匿ファイルは本項の対象外とし、値を書き換えない。
