## 完了前の実描画確認

画面キャプチャは、描画ツールが書き込める場所へ保存し、その絶対パスを記録する。PlaywrightのライブラリやE2Eテスト環境を利用する場合は、managed-tempへ直接保存する。
保存先が制限されているブラウザ操作ツール（`@playwright/mcp`など）を利用する際は、ファイル名を指定せずに保存し、ツールから返されたパスを絶対パスとして解決して記録する。ファイル名を指定すると作業ディレクトリを基準に解決され、出力ディレクトリや作業ディレクトリ外への書き込みが拒否されるためである。出力ディレクトリが対象の作業ツリー内に位置する場合は、managed-tempへ移動してから記録する。
