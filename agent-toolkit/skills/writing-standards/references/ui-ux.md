品質基準の正式な提供元は`agent-basics:writing-standards`の`references/ui-ux.md`である。呼出元が指定した条件と読込範囲を、同名の正式な品質資料へ引き継ぐ。節指定がある場合は移設先の実見出しへ接続し、指定がない場合は従来の全文読込契約を保つ。

以下はagent-toolkitが所有する運用条件である。呼出元の条件と読込範囲に従い、ここに残る運用節を補う。

## 完了前の実描画確認

画面キャプチャーは描画手段が書き込める場所へ保存して絶対パスを記録する。PlaywrightのライブラリとE2E環境ではmanaged-tempへ直接保存する。
保存先を制限するブラウザー操作ツール（`@playwright/mcp`など）ではファイル名を指定せずに保存し、応答が示すパスを絶対パスへ解決して記録する（ファイル名を指定すると作業ディレクトリ基準で解決され、出力ディレクトリと作業ディレクトリの外への書込は拒否される）。出力ディレクトリが対象の作業ツリーの中なら、managed-tempへ移してから記録する。
