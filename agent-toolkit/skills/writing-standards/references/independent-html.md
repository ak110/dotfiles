# 単体HTML成果物のスタイル規範

本書はブラウザーで開くだけで表示が完結する単体HTML成果物の実装指針を定める。

## 適用範囲

対象はユーザーへ単体成果物として提示するHTML（レポート・ダッシュボード・可視化・プレゼン・プロトタイプ等）とする。
Webシステムの一部として動作するHTML（既存フレームワークのテンプレート・コンポーネント等）は、そのフレームワークやプロジェクトの規範に従う。

## 実装指針

- 成果物は単一のHTMLファイルへまとめ、外部ファイルへ分割しない
- スタイルはCDN経由のCSSフレームワーク（`daisyUI`等）で統一し、インラインスタイルの多用を避ける
- ネットワークへ接続しない環境での表示が要件の場合だけ、CDN読み込みに代えてCSSとJavaScriptをファイル内へ埋め込む
- 単体で開いて主要な操作を完了できる構成にし、情報密度と目的の情報への到達性を両立させる
- テーマ切替・navigation・export・編集とpreviewの配置は用途で選び、一律に追加しない

## 技術選択の指針

標準のHTML/CSS/JavaScriptで成立する範囲は独自実装せず、フレームワークをCDN経由で読み込む。
外部APIやサーバー連携を要する構成は単体成果物の用途から外れるため、Webシステム側の規範に従う。
