# 依頼ごとのスキル選択

`skills.json`は、この課題で使えるスキルの識別子、`description`、本文（`body`）、条件付き参照資料の一覧である。
`task.py`の`select`を修正し、依頼IDごとに選ぶスキルの識別子を返す。

- `initial`: 依頼と`description`から、本文を読む前に選ぶスキル
- `additional`: `initial`で選んだスキルの本文を読んで、追加で選ぶスキル

依頼に必要なスキルだけを選ぶ。依頼の作業に当てはまらないスキルは、同じ語を含んでいても選ばない。
`skills.json`に無い識別子は使わない。
追加の質問は不要であり、公開関数の引数と戻り値の形式を維持して提出する。

| 依頼ID | 依頼 |
| --- | --- |
| `article-eval` | この外部記事の主張を根拠に、私たちの検証手順の改善案が妥当かを評価して。文書やコードは変更しない。 |
| `paraphrase` | ブログ記事の言い分をもとに、テストの手順を変える提案が良いかどうかを見てほしい。ファイルは触らなくていい。 |
| `edit-and-check` | `config.toml`のタイムアウトを30秒へ直して、チェックを通して。 |
| `bug-explain` | ログイン時に500エラーになる原因と、再発を防ぐ対策を説明して。修正はまだしなくていい。 |
| `known-fact` | Pythonのlistとtupleの違いを一言で教えて。 |
| `boundary` | このX投稿の内容を要約して、社内向けの説明文書を新しく作って。 |
