# 計画準拠の実装差分レビュータスク

## 入力

- `plan-codex-implementation-review.md`と本ファイルの絶対パスを受け取り、着手時に全文を読む
- 計画ファイル、品質規範、プロジェクト規範の絶対パスを受け取り、着手時に全文を読む
- 計画着手前SHA、`HEAD`、作業ディレクトリの絶対パスを受け取る
- 必須入力が欠ける場合は欠落項目を返し、推測で補わない

## レビュー

- 計画着手前SHAから`HEAD`までの実差分と変更後ファイルを確認する
- 要件・計画項目の充足、計画からの逸脱、許容済み挙動変化、検証、文書、
  テスト、生成・配布経路の追随を点検する
- 計画と実差分が一致しない場合は、計画の意図、進捗ログ、現行実装を照合する
- 対象成果物を読み取り専用として扱う

## 出力

- 指摘ごとに系統内通番、重大度、観点、区分、箇所、内容、再現根拠、修正方針を返す
- 指摘がない場合は「指摘なし」と明記する
