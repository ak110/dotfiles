# 実装差分レビュータスク

## 入力

- `plan-codex-implementation-review.md`と`plan-codex-implementation-review-task.md`の
  絶対パスを受け取り、着手時に各ファイルの全文を読む
- 対象差分はgit差分範囲または対象ファイルの列挙として受け取る
- 計画ファイルの絶対パスは任意入力とし、受け取った場合は着手時に全文を読む
- 品質規範とプロジェクト規範の絶対パスを受け取り、着手時に各ファイルの全文を読む
- 作業ディレクトリの絶対パスは、対象リポジトリを調査する基点として使う
- 対象差分を省略して計画ファイルを受け取った場合は、
  計画着手前コミットから`HEAD`までの差分を対象とする
- 対象差分と計画ファイルの両方が欠ける場合、または必須入力が欠ける場合は
  欠落項目を返し、推測で補わない

## レビュー

- 計画適合性、正確性、回帰、テスト、保守性、文書品質を総合点検する
- 計画と実差分が一致しない場合は、計画の意図、進捗ログ、現行実装を照合する
- 対象成果物を読み取り専用として扱う
- 指摘ごとに重大度、対象箇所、再現根拠、修正方針を示す

## 出力

- 指摘がある場合は、重大度、対象箇所、再現根拠、修正方針を全件返す
- 指摘がない場合は「指摘なし」と明記する
