# 計画ファイル機械チェック・修正タスク

## 入力

- `plan-codex-review.md`と`plan-codex-review-fix-task.md`の絶対パスを受け取り、
  着手時に各ファイルの全文を読む
- 計画ファイル、品質規範、対象固有スキルの絶対パスを受け取り、
  着手時に各ファイルの全文を読む
- 作業ディレクトリの絶対パスは、対象リポジトリを調査して一時複製を検査する基点として使う
- 入力が欠ける場合は欠落項目を返し、推測で補わない

## 機械チェック・修正

- `plan-codex-review.md`「機械チェック委譲」節の検査、違反修正、再検査を全て実施する
- 受領した計画ファイルの絶対パスを明示的な書き込み許可先とする
- 対象リポジトリでは、同節が定める一意な一時複製の作成と除去だけを書き込み対象とする
- 計画ファイルと一時複製以外のファイルを変更しない
- 一時複製の除去後に、計画ファイルの実体と検査結果を再確認する

## 出力

- 各検査の初回と最終の終了コード、error件数、warning件数を`check_results`へ記載する
- 一時複製の除去結果と`git status --short`による残存確認結果を`check_results`へ記載する
- 解消できない違反または実行不能がある場合は、原因を`escalation_points`へ記載する
