# 独立した実装差分レビュータスク

## 入力

本節を独立レビュー系へ渡す資料契約の正本とする。

- `plan-codex-implementation-review.md`と本ファイルの絶対パスを受け取り、着手時に全文を読む
- 変更ファイル一覧、計画着手前SHA、品質規範、プロジェクト規範、作業ディレクトリ、
  独立系専用の再現証跡ディレクトリの絶対パスを受け取る
- 作業場所、書込主体、出力言語、プロセス所有権、不可逆操作権限と許可範囲を受け取る
- `review_contract`として、ユーザーが明示・合意した現行の外部契約、または適用規範により
  確定した契約、入力生成主体、信頼境界、通常入力、対象外入力、誤許可と誤拒否の利用者影響を
  要約して受け取る。ユーザー発話全文、作者の推論、変更意図、実装方針は含めない
- 品質規範はスキル名で受け取り、各スキルのトリガー規則に従って着手時に全文を読む
- プロジェクト規範は絶対パスで受け取り、着手時に全文を読む
- 必須入力が欠ける場合は欠落項目を返し、推測で補わない

計画、進捗ログ、ユーザー発話の全文、変更意図、許容済み挙動変化、コミットメッセージ、
計画準拠系を含む他レビューの出力は入力として受け取らず、参照しない。

## レビュー

- `git diff <計画着手前SHA>..HEAD -- <変更ファイル一覧>`と変更後ファイルを確認する
- 必要に応じて呼び出し元、参照元、テスト、生成・配布経路を調査する
- 正確性、回帰、境界条件、テスト不足、保守性、規範適合を点検する
- 重大度と検証する入力集合は`review_contract`が宣言する境界へ合わせる
- `plan-codex-implementation-review.md`「初回レビュー」節が定める導出観点を点検する
- 外部ツール・外部実行系の挙動を根拠とする指摘は、専用の再現証跡ディレクトリ内の最小再現で裏付ける
- 再レビューでは、実装・修正系が返した一括修正後の影響監査について、点検対象と結果を照合する
- 計画ファイル、進捗ログ、コミットメッセージ、他レビューの出力を調査対象に含めない
- 対象成果物を読み取り専用とし、書き込みは専用の再現証跡ディレクトリだけへ行う

## 出力

- 対象commitと点検範囲を返す
- 指摘ごとに系統内通番、重大度、観点、箇所、内容、`violated_contract`、再現根拠、修正方針を返す
- 実在する欠陥だけを返し、好み、将来仮定、目的外改善を指摘しない
- 計画対応・独立提案の区分は返さない。区分判定は実装・修正系が担う
- 一括修正後は、修正後の最終検証と再レビュー結果を返す
- 再レビューで新規指摘を返す場合は、同referenceが定める3分類のいずれかを根拠付きで示す
- `external_execution`へ所有主体、安定した実行識別子、開始時刻、直近の生存確認時刻と結果を記載する。
  外部実行を保持しなかった場合は`not_applicable`とする
- `reproduction_evidence`へコマンド、主要な環境条件、終了コード、標準出力、標準エラー、証跡パスを記載する。
  外部ツール主張を扱わなかった場合は`none`とする
- 指摘がない場合も、対象commit、点検範囲、短い「指摘なし」を返す
