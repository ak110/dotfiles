# 規範どうしが矛盾する場合の由来確定

本書は`agent-toolkit/rules/01-agent.md`「方針が衝突する場合の優先順位」が定める、規範どうしの矛盾を扱う手順を定める。

規範どうしが矛盾する場合は、優先順位を適用する前に各条文の由来を確定する。由来を確定しないまま優先順位を適用すると、ユーザー指示に由来する条文を下位の規範として扱い、合意済みの要件を取り消すことになる。
`git log -S`等で導入変更を特定し、ユーザーの明示的な指示とエージェントの判断のどちらに由来するかを判別する。対応するキュー項目と計画ファイルがあれば、その項目の`source`と明示由来、計画の実施内容の由来欄を入力にする。
由来を確定できない場合も、由来不明だけで修正可否を問わず、現行の明示要求、判断記録と優先順位を調べて`SKILL.md`「確認要否の判定」を適用する。目的・要件・結果と既存認可を保てる是正は自ら確定して報告し、合意済みの目的側の要求を取り消す修正と、ユーザーだけの資料・判断が必要な修正は、必要な部分を確認する。
本書が扱うのは矛盾する条文そのものの修正であり、作業中にどちらの規範に従って進むかは`references/procedure-conflict.md`の判定順に従う。
