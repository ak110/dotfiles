# Codexでの質問表示

ユーザー確認の方法は`agent-toolkit/share/rules-main.codex.md`が定める。同書の条件に合う構造化質問が無い場合だけ、次の固定形式で質問を提示する。質問が複数ある場合も、各質問を同じ単位で分ける。

```text
**Q1** - **<質問タイトル>**: <質問本文。複数段落や複数の選択肢を含めてもよい>
共通前提: <全選択肢が共有する前提と外した案の扱い、および選択肢の評価が依存する技術的事実（作成する主体、その時点でそろう情報など）。いずれも無い場合は「なし」を推奨>

推奨: <推奨回答>

---

**Q2** - **<質問タイトル>**: <質問本文。複数段落や複数の選択肢を含めてもよい>
共通前提: <全選択肢が共有する前提と外した案の扱い、および選択肢の評価が依存する技術的事実（作成する主体、その時点でそろう情報など）。いずれも無い場合は「なし」を推奨>

推奨: <推奨回答>
```
