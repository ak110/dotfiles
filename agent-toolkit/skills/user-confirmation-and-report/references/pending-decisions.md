# 未確定判断の保留と回答の受領

本書はメインエージェントが、回答を得られない確認の保留、無回答後の確認の記録、事前承認の合意判定、対話中のUWIへの回答の受領を扱う手順を定める。確認要否の判定と手段の選択は`SKILL.md`が定める。

## 未確定判断の保留と暫定判断

`SKILL.md`「確認を要する事項」はモードによらず確認へ送る。自律モードで回答を得られない場合は`agent-toolkit:wi-standards`を起動しUWIへ記録する。無回答と判定する契機と最初からUWIを使う環境は`SKILL.md`「手段の選択」の表に従う。
`SKILL.md`「確認要否の判定」3の曖昧さは、自律モードでも事前承認型UWIへ記録し、回答に依存する元項目をwi-standards「状態と依存」で保留する。暫定判断で埋めず、依存しない成果物・工程だけを続ける（無回答で確定すると意図と異なる成果と是正の往復を生む）。
回答を得ないまま確認が終わった場合（協調モードのセッションの終了を含む）は、モードによらず未解決の判断をUWIへ移す。同セッションで無回答の終了を観測した自律モードのエージェントは、以降の確認をUWIへ記録し、依存する元項目だけを`atk wi hold`で保留する（処理中なら`atk wi hold --state=processing <元項目のファイル名>`）。工程を止める前に確認事項を記録する。

必須外部資料を得られなければ提供を依頼し、依存する成果物だけを保留する。暫定判断は要求範囲を保つ成果の確定だけに使う。資料なしの続行は範囲縮小として他の論点と分けて確認する。協調モードは資料か要求範囲への明示回答を待つ。自律モードは元項目のファイル名・説明・保留理由・必要資料・回答で変わる結果をUWIへ記録し、元項目を保留して依存しない工程を続ける。
解除条件・再開工程はユーザーの判断材料ではないため、元項目の計画の進捗ログか引き継ぎ記録へ置き、UWIの元項目からたどれるようにする。

## 事前承認の合意判定

`references/approval-scope.md`が事前承認とする操作は、協調モードの無回答時も自律モードのUWI記録後も、合意まで暫定判断から除き、可逆な代替か保留を選んで依存しない工程を続ける。事後承認対象と成立済み承認内の操作は通常どおり進める。

## 回答の受領

対話中に得たUWIへの判断（保留中の確認への判断も含む）は回答として記録する。その後の変更着手は`agent-toolkit:process-wi`など専用手順の起動か明示指示がある場合に限る。
専用手順の実行中、現在の主題を保留したUWIの回答を得たら、記録に続いて保存済み計画・工程を同セッションで再開する。元の要求と計画に属する未完了範囲はAWIや追加の採否確認へ分けず完遂し、範囲外の新要求だけを別項目にする。
