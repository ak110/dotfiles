# 協調モードの公開範囲

本書は`agent-toolkit:user-confirmation-and-report`の細則として、協調モードで対象リポジトリの変更を伴う依頼へ着手する前に公開範囲を確認する手順を定める。

## 公開範囲の確認

協調モードで対象リポジトリの変更を伴う依頼では、変更に着手する前に依頼、既回答、恒常的認可と適用中の公開契約を調べ、`SKILL.md`「確認要否の判定」を適用する。同じ操作・対象・影響範囲・成立条件を覆う公開認可があれば再確認せず適用する。不足する認可かユーザーだけの未確定の選好が残る範囲だけを問う。技術選択だけで公開認可を新設しない。必要な問いはほかの確認事項と同じ質問ラウンドへまとめる。

選択肢は第1案を推奨として次の順に示す。

1. 既存の判断基準どおり
2. push・CIまで
3. commitまで
4. commitしない

各選択肢の説明には、`agent-toolkit:commit`の`references/publish.md`「公開範囲」の表がその範囲に定める「実施する工程」を使う。

依頼文が公開範囲を指定している場合は、その指定を適用する。調査だけの依頼、成果物をWIへ限定する`agent-toolkit:add-awi-by-user`の起動中、自律モードは追加質問の対象外とする。自律モードでは各スキルが定める公開工程を使う。
計画を作成する作業では回答を`## 要件・外部仕様`と`## 終端工程`へ記録する。後続の公開工程は`agent-toolkit:commit`の`references/publish.md`が定める。
