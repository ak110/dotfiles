# 判断詳細の品質基準

<!-- read-source: agent-basics:review-standards/references/judgment-details.md -->

判断詳細に関する品質基準の定義元は、`agent-basics:review-standards`の`references/judgment-details.md`である。呼び出し元が指定した条件や読み込み範囲は、同名の正式な品質資料へそのまま引き継ぐ。特定の節が指定されている場合は移行先の実在する見出しへ接続し、指定がない場合は従来の全文読み込みルールを維持する。すでに取得済みの同じバージョンの本文がある場合は、再取得せずにそのまま使用する。
