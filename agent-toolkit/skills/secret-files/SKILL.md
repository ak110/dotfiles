# 秘匿値ファイルの取り扱い

本スキルは、秘匿値を含むファイルの読取と書換の制約を提供する。

秘匿値を含むファイル（`.env`、`.env.<接尾辞>`、鍵、証明書などの、値の秘匿を前提とするファイル）は、
必要なキーの値だけを取り出す操作に限って読む。全文の読み取り、出力及び複製を禁止する。
全文がログ、トランスクリプト、生成物などへ複写されると秘匿値が露出する。
同一リポジトリのworktreeへ実行前提ファイルを複製する操作は、本項の対象の外に置く。
`agent-toolkit:delegation`の`references/mandatory-rules.md`が、その操作を認証情報の再配置の禁止対象から除いているためである。

動作確認のために`.env`及び`.env.<接尾辞>`の値を追記、変更又は削除する操作は、
Bashの追記（`echo ... >>`）又は`sed -i`で行い、書き換え手段をこの2つに限る。
鍵、証明書などの他の秘匿ファイルは本項の対象外とし、値を元のまま保つ。
書換を許容する対象を`.env`系に限るのは、動作確認のために値の追記、変更と削除を要する対象が
その系統に限られるためである。書換手段をBashの追記と`sed -i`へ限るのは、編集ツールによる
書き換えが全文置換として働き、その操作で原本が消失するためである。
