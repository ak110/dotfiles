# 秘匿値ファイルの取り扱い

本スキルはプロジェクトのGit作業ツリー外にある秘匿値ファイルの読取と書換の制約を提供する。

作業ツリー内のファイルは、Git追跡やgitignore、ファイル名、拡張子によらず通常のファイルとして扱う。
`.env`、鍵、証明書なども通常の読取・編集・複製・全文比較・出力の対象とし、本スキルの制約を適用しない。
作業ツリー内から外部の認証情報を参照する場合は、認証情報の実体の位置で内外を判定する。

秘匿値を含むファイル（`.env`、`.env.<接尾辞>`、鍵、証明書などの、値の秘匿を前提とするファイル）は、
必要なキーの値だけを取り出す操作に限って読む。全文の読み取りと出力を禁止する。
全文がログ、トランスクリプト、生成物などへ複写されると秘匿値が露出する。

動作確認のために`.env`および`.env.<接尾辞>`の値を追記、変更または削除する操作は、
Bashの追記（`echo ... >>`）または`sed -i`で行い、書き換え手段をこの2つに限る。
鍵、証明書などの他の秘匿ファイルは本項の対象外とし、値を元のまま保つ。
書換を許容する対象を`.env`系に限るのは、動作確認のために値の追記、変更と削除を要する対象が
その系統に限られるためである。書換手段をBashの追記と`sed -i`へ限るのは編集ツールが
事前の全文取得を要して秘匿値を読み込み、全文取得を経ない書込ツールは全文置換として働いて
原本の他の値を失うためである。
