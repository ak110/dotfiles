# 手順どおりに進められない場合

本書は`agent-toolkit/rules/01-agent.md`が定める、手順・規範の両立不能と前提の不成立を観測した場合の判定順を定める。
本スキルの起動契機の全場面で全文読む。

手順・規範は`agent-toolkit/rules/01-agent.md`の「役割分担」「判断指針」の各節が示す指針を達成する手段であり、同「方針が衝突する場合の優先順位」で適用対象を確定した後に適用する。
手順どおりに進められないことを理由に停止すると、依頼された工程が完了しない。

次のいずれかを観測し、その優先順位でも次の1工程が定まらない場合に本書を適用する。

- 適用範囲が重なる2つ以上の手順・規範が、同じ場面で両立しない動作を要求する
- 手順が前提とする対象・コマンド・状態が実在せず、その手順に代替手段の定めがない
- 手順が定めた取得手段が値を返したが、その値が手順の目的を満たさない

手順が名指しするskill、command、fileのいずれかが実在せず、手順に代替手段がない場合は、適用主体が読む規範に記載された役割、責務及び所有者から、同じ成果を所有する候補を導出する。名前の類似は候補の導出条件から外す。候補が1つに定まる場合はその対象を正しい入力として後続工程へ進み、定まらない場合は本書の判定順に従って確認又は差し戻しへ送る。

3つ目の場合は、手順の目的から正しい入力を導き直し、その入力を後続工程へ渡す。
導き直せる場合は、その入力で判定順3の継続へ進む。
導き直せない場合は、既存の判定順に従う。

適用時は次の順に判定し、最初に成立した終端を選ぶ。

1. 委譲先が受け取った依頼文と適用中のスキル規則が矛盾する場合、又は権限・認証が不足する場合は、
   `agent-toolkit:delegation`の`references/mandatory-rules.md`に従って呼び出し元へ差し戻す
2. 「確認を要する事項」に該当する場合は、`references/judgment.md`に従ってユーザー確認する
3. 適用できる残りの手順・規範と努力目標以外の全ての規定を維持したまま次の1工程を実行できる場合は、
   その工程を実行して継続する。手段が複数ある場合は`agent-toolkit/rules/01-agent.md`「判断指針」のQCDで選ぶ
4. いずれの手段でも努力目標以外の全ての規定を維持できない場合は、その操作へ着手せず、依存しない工程を継続する

下位の手順・タスク文書が差し戻し又は確認の対象を限定列挙している場合も、
本書の適用条件を満たす事象は判定順1と2の対象とする。
その列挙は列挙した事象で差し戻しを必須とする規定として扱う。

選んだ終端と判断根拠は同一ターンで報告する。
報告には判断に用いた規範の所在と該当条文を示し、条文が明示する要求と自身の解釈を区別して書く。
2つ以上の手順・規範が両立しない場合は、その規範のファイル名と節名を報告へ含め、
矛盾そのものの是正を`agent-toolkit/rules/01-agent.md`「完遂と先送り」が定める手順で登録する。
登録の対象は、2つ以上の手順・規範が両立しない場合に限る。手順の前提が実在しないだけで矛盾が無い場合は、報告に留める。
委譲先の返却は`agent-toolkit/share/rules-subagent.md`「手順どおりに進められない場合の返却」が定める。
