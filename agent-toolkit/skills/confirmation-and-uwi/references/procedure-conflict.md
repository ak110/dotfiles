# 手順どおりに進められない場合

本書は`agent-toolkit/rules/01-agent.md`が定める、手順・規範の両立不能と前提の不成立を観測した場合の判定順の正本である。
本スキルの起動契機の全場面で全文読む。

手順・規範は`agent-toolkit/rules/01-agent.md`の「役割分担」「判断指針」「行動指針」の各節が示す指針を達成する手段であり、同「方針が衝突する場合の優先順位」で適用対象を確定した後に適用する。
本書は厳守規定とする（手順どおりに進められないことを理由とする停止は、依頼された工程を完了させないため）。

次のいずれかを観測し、当該優先順位でも次の1工程が定まらない場合に本書を適用する。

- 適用範囲が重なる2つ以上の手順・規範が、同じ場面で両立しない動作を要求する
- 手順が前提とする対象・コマンド・状態が実在せず、当該手順に代替経路の定めがない
- 手順が定めた取得手段が値を返したが、当該値が当該手順の目的を満たさない

手順が名指しするskill、command又はfileが実在せず、手順に代替経路がない場合は、名前の類似だけから別の対象へ置換しない。適用主体が読む規範に記載された役割、責務及び所有者から、同じ成果を所有する候補を導出する。候補が1つに定まる場合は当該対象を正しい入力として後続工程へ進み、定まらない場合は本書の判定順に従って確認又は差し戻しへ送る。

3つ目の場合は、返った値を後続工程の入力とせず、当該手順の目的から正しい入力を導き直す。
導き直せる場合は、当該入力で判定順3の継続へ進む。
導き直せない場合は、既存の判定順に従う。

適用時は次の順に判定し、最初に成立した終端を選ぶ。

1. 委譲先が受領した依頼文と適用中のスキル規則が矛盾する場合、又は権限・認証が不足する場合は、
   `agent-toolkit:delegation`の`references/mandatory-rules.md`に従って呼び出し元へ差し戻す
2. 「確認を要する事項」に該当する場合は、`references/judgment.md`が定める経路へ送る
3. 適用できる残りの手順・規範と全ての厳守規定を維持したまま次の1工程を実行できる場合は、
   当該工程を実行して継続する。手段が複数ある場合は「判断指針」で選び、
   優劣が付かない場合だけ「行動指針」の時間効率とコストで選ぶ
4. いずれの手段でも全ての厳守規定を維持できない場合は、当該操作へ着手せず、依存しない工程を継続する

下位の手順・タスク文書が差し戻し又は確認の対象を限定列挙している場合も、
本書の適用条件を満たす事象は判定順1と2の対象とする。
当該列挙は、列挙した事象で差し戻しを必須とする規定として扱う。

`agent-toolkit/rules/01-agent.md`「手順の目的照合」で目的の既達又は前提の不成立を確定できず、手順が過剰と判断しただけの場合は本書を適用しない。
`agent-toolkit:review-standards`の`review-standards/references/judgment-details.md`「規定の適用可否」に従って規定どおり適用し、改訂を提案する。

選んだ終端と判断根拠は同一ターンで報告する。
報告には、判断に用いた正本の所在と該当条文を示し、当該条文が明示する要求と自身の解釈を区別して書く。
2つ以上の手順・規範が両立しない場合は、当該規範のファイル名と節名を報告へ含め、
矛盾そのものの是正を`agent-toolkit/rules/01-agent.md`「完遂と先送り」が定める登録の経路で登録する。
手順の前提が実在しないだけで矛盾が無い場合は、報告に留めて登録しない。
委譲先の返却は`agent-toolkit/share/rules-subagent.md`「手順どおりに進められない場合の返却」が定める。
