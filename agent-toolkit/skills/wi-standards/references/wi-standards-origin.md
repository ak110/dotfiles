# AWIとUWIの共通規範：由来と承認

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

## 由来と承認

frontmatterで`source`が省略されている項目のみを人間由来の初期値として扱う。
`source`に値が設定されている項目は、要求単位の由来がユーザー専用の記入欄、計画の由来欄、逐語引用のいずれかで裏付けられない限りエージェント由来とみなす。
起草者が「ユーザーの要件」と要約した記述も、逐語引用に無い範囲はエージェント由来とする。
人間由来の要求単位を全部または一部不採用とする場合や、ユーザーが範囲語や開放列挙で示した対象集合を狭める場合は、ユーザーによる明示的な承認を必要とする。
AWIの`## ユーザーコメント`およびUWIの`## 回答`は、ユーザー専用の記入欄である。
詳細な運用は`origin-and-approval.md`が定める。
