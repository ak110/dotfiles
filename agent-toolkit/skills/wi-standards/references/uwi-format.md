# UWI本文の書式

全UWIは、回答者が回答対象を識別できる疑問文を1文以上含める。`--question-type=choice`では選択肢の提示を問いとして扱う。本文だけで判断できるよう、対象、背景及び判断根拠を含める。回答者が選ぶ問い・選択肢を本文冒頭へ置き、背景・経緯・原因分析は問いの後へ簡潔に置く。識別子は対象との関係を示す文脈語とともに用いる。

`atk wi add --type=uwi`へ渡す本文は質問本文だけとし、ツールが自動付与する`## 質問`見出し、`## 回答`以降及び回答欄マーカーを含めない。既存UWIを起草の起点にする場合は、当該見出しと回答欄を除去する。質問本文内の`## 回答方法`節は保持する。

外部環境の実機確認を依頼する場合は、対象環境・事前条件・番号付き操作、確認場所と取得値、本文へ直接記載した期待値、回答欄へ貼り付ける最小の返信形式及び確認できない場合の記載内容を含める。

複数項目の判断を求める場合は、変更前後が分かる差分又は対象全文、各項目の採用と不採用の影響、起票者の推奨と根拠を示す。項目が4件以上の場合は共通する判断基準で群にまとめ、群単位の一括回答を許容する。
