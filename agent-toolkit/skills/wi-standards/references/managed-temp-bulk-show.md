# 複数件の`atk wi show`の取得

同一の対象リポジトリの複数のキュー項目を同一工程で取得する場合は、実行ツールの戻り値の切り詰めで本文を失わない状態を満たす。
`atk wi show <filename>... --skip-pull`を対象リポジトリごとに単独で1回発行し、リダイレクトやパイプを付けない。
エージェント環境では、FILENAMEを2件以上指定した`atk wi show`は量によらず全量を新規managed-tempへ保存し、標準出力へ`保存先: <絶対パス>`と`行数: <N>`を返す。
呼び出し側は保存先を組み立てず、返された`保存先:`の絶対パスのファイルを読んで完全性を判定する。

本文として採用するのは、終了コード0で、保存ファイルに要求した全ファイル名の`### <ファイル名> [<状態>]`見出しがある場合だけとする。
見出しが欠けた項目だけを単数で再取得する。
非0終了の部分出力は採用せず、取得主体の工程が定める手順（停止か、要求した項目の単数での再取得）へ進む。
出力順序と本文境界は`atk wi show`のCLI契約とする。

エージェント環境でない場合など`保存先:`の行が無く本文が直接表示された場合は、表示された本文で同じく判定する。
保存ファイルを読めない場合は、要求した項目を単数で取得する。

対象リポジトリまたは取得条件が異なる場合は集合を分ける。
単一項目の取得、警告・エラー後のその項目だけの再取得、およびUWIの回答確認では、単数形の取得をそのまま使う。
単数形の取得は16384バイト以下なら本文を直接表示し、超える場合は同じく`保存先:`と`行数:`を返す。
