# 一括取得の管理対象一時領域

同一の対象リポジトリの複数のキュー項目を同一工程で取得する場合は、実行ツールの戻り値の切り詰めで本文を失わない状態を満たす。
`atk wi show <filename>... --skip-pull`の標準出力を管理対象一時領域のファイルへ保存し、保存したファイルの内容で完全性を判定する手段が一般的に有効である。
領域は対象リポジトリごとに1回作成し、SessionStartが領域を通知している場合はその配下へ作成する。

本文として採用するのは、終了コード0で要求した全項目が出力された場合だけとする。
非0終了の部分出力は採用せず、取得主体の工程が定める手順（停止か、要求した項目の単数での再取得）へ進む。
出力順序と本文境界は`atk wi show`のCLI契約とする。

領域の作成、保持、回収及び消費工程の完了判定では`agent-toolkit:managed-temp`をSkill機能で起動する。
標準出力のファイル保存、絶対パスの読取、領域の作成のいずれかが成立しない場合は、分割取得へ代替する。

対象リポジトリ又は取得条件が異なる場合は集合を分ける。
単一項目の取得、警告・エラー後のその項目だけの再取得、及びUWIの回答確認では、単数形の取得をそのまま使う。
