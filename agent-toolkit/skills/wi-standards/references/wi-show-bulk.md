# 複数件の`atk wi show`の取得

同じ対象リポジトリにある複数の項目を同一工程で取得する場合は、対象リポジトリや取得条件ごとに`atk wi show <filename>... --skip-pull`を1回実行する。このとき、リダイレクトやパイプは使わずに単独で実行する。エージェント環境では出力内容がファイルへ自動保存され、標準出力には`保存先:`と`行数:`が返される（詳しい条件は`atk wi show --help`を参照）。出力された`保存先:`のファイルを読み込み、本文が途中で切り詰められていないことを確認する。

取得した内容を正式な本文として採用するのは、コマンドの終了コードが0であり、要求したすべてのファイル名に対応する`### <ファイル名> [<状態>]`見出しが揃っている場合に限る。見出しが欠けている項目があるときは、その項目だけを単独で再取得する。終了コードが0以外となった場合の部分出力は破棄し、取得元工程が定める手順（処理の停止、または1件ずつの再取得）へ進む。
もし`保存先:`の行が出力されず本文が直接表示された場合は、その表示内容をもとに同様に判定する。保存先ファイルを読み取れない場合は、各項目を単独で取得し直す。
単一項目の取得、警告やエラーが発生した後の再取得、およびUWIの回答確認を行うときは、項目を1件ずつ指定して取得する。
