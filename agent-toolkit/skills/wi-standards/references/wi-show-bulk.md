# 複数件の`atk wi show`の取得

同じ対象リポジトリの複数項目を同じ工程で取得する場合は、`atk wi show <filename>... --skip-pull`を対象リポジトリと取得条件ごとに1回、リダイレクトやパイプを付けずに実行する。エージェント環境では出力が保存され、`保存先:`と`行数:`が返る（条件は`atk wi show --help`）。返された`保存先:`のファイルを読み、本文が切り詰められていないことを確かめる。

本文として採用するのは、終了コード0で、要求した全ファイル名の`### <ファイル名> [<状態>]`見出しがある場合だけとする。見出しが欠けた項目だけを単数で再取得する。非0終了の部分出力は採用せず、取得した工程が定める手順（停止か単数での再取得）へ進む。
`保存先:`の行が無く本文が直接表示された場合はその本文で同じく判定し、保存ファイルを読めない場合は単数で取得する。
単一項目の取得、警告・エラー後の再取得、UWIの回答確認は単数形で取得する。
