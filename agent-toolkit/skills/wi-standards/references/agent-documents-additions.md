# エージェント向け文書への追記と記述量の管理

品質基準の正式な提供元は`agent-basics:writing-standards/references/agent-documents-additions.md`である。
呼び出し元の読込条件を引き継ぎ、本書の運用条件と条件に該当する正式な資料の全文を読む。
両方に同じ主題があれば、両方の全文を確認する。
範囲の選択と取得済み本文の再利用は`agent-basics:writing-standards/references/read-method.md`に従う。

以下はagent-toolkit固有の運用条件である。

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

| 時点または条件 | 全文読む資料 |
| --- | --- |
| 「新設と改訂の評価」の評価を起動する前 | `agent-toolkit:refine-prompt/SKILL.md` |

## 新設と改訂の評価

- スキル、役割文書（`<役割名>.subagent.md`）、常時規範の節を新しく作る場合は、レビューへ渡す前に`agent-toolkit:refine-prompt`を起動し、シナリオを与えて評価する。
  対象は利用頻度の高いスキルと自動化の中核となる文書に限り、起動の費用に見合わない単発のプロンプトは対象外とする。
- 指示と挙動の食い違いを原因分析し、指示文の改訂が必要と確定した場合は、改訂案を同じ方法で評価する。
- 評価の対象はこの2つの場合に限り、どちらにも当たらない既存の規範の改訂は対象外とする。

## 常時規範への追記条件

- ユーザーへの発話に適用する規定は、`agent-toolkit:/share/rules/rules-main.md`の「ユーザー向け発話ルール」節にのみ配置する。
  守らないとユーザーへ意図が伝わらない条文に限定する（努力目標。発話のたびに参照する規定が増えると本来の作業へ回せる能力が減るため）。

## 既存対象への波及

- 同一の事象に対して相反する判断を下す条文を併存させない。
  矛盾する既存条文がある場合は、同一の変更で置き換えるか優先順位を明確にする。
  管轄が別リポジトリにまたがる場合は、該当リポジトリ向けのAWIに記録する。

- 努力目標以外の規定を追加または強化した場合は、その規定の適用対象となる既存の成果物も走査する。
  作業認可の範囲内にある違反は同じセッションで修正し、書込権限の範囲外であればWIとして起草する。
  規定の追加前に作成され、追加後も継続して利用される成果物も対象に含める。
  重大度に応じて未知の問題の探索を打ち切る基準と、是正すべき範囲を区別して扱う。
  努力目標の規定は新規の記述から適用する。
