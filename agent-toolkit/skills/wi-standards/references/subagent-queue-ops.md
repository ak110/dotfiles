# 委譲先によるprivate-notesへの反映

本書は、委譲先が`atk wi`でキュー項目の状態を変更する際に、反映を抑止する指定をどのように扱うかを定める（`agent-toolkit/share/rules-subagent.md`の委ねによる）。

- 委譲先が状態を変更する`atk wi`を実行するときは、反映を抑止するオプションを付けずに実行する。一連の操作の途中で`atk wi adopt`や`atk wi reject`に`--skip-push`を使った場合は、最後の操作でこの指定を外し、未pushのローカルcommitを残さずにリモートへ反映する。ローカルに未pushのcommitが残ると、別セッションとの同期時に履歴が分岐するためである。
- `atk plans commit`による計画バンドルの保存は本規定の対象外とする。抑止指定を利用できる条件は、保存を指示する各手順の定めに従う。
