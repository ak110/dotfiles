# 委譲先によるキュー管理リポジトリへの反映

本書は`agent-toolkit/share/rules-subagent.md`が委ねる、委譲先が`atk wi`の状態変更操作を行う場合の反映抑止指定の扱いの正本である。
AWI又はUWIの状態遷移を委譲先が扱う場面で読む。

- 委譲先は、AWI及びUWIのキュー項目の状態を変更する`atk wi`の操作で、キュー管理リポジトリへの反映を抑止する指定（`atk wi adopt`及び`atk wi reject`の`--skip-push`）を用いず、既定の反映のまま実行する。連続する当該操作の中間で当該指定を用いた場合は、最後の操作で指定を外し、未pushのローカルcommitを残さずに終える（厳守規定。反映されないローカルcommitは、正本から取得できず他主体の同期を分岐させる）
- `atk plans commit`による計画バンドルの保存は前項の対象外とする。当該操作で反映を抑止する指定を用いてよい条件は、当該保存を指示する手順が定める
