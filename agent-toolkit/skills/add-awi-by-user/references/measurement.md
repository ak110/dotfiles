# 完成条件や採否が依存する値の測定

本書は`agent-toolkit:add-awi-by-user`のセッションで完成条件や採否が依存する値を測定する主体へ、成果物の制限の例外として行う測定と一時的な変更の手順を定める。測定の後は対象リポジトリの作業ツリーを測定前の状態へ戻す。

## 測定の手順

測定は次の順に行う。

1. 環境変数、引数または別の設定ファイルの指定で追跡ファイルを変えずに実施できる方法を先に使う
2. 追跡ファイルの変更が必要な場合は測定前の`git status --porcelain=v1`を保存し、変更対象と測定が書き換え得るパスに既存差分があれば`git worktree add --detach`で作成した検証用worktreeで測定する
3. 元の作業ツリーで測定した場合は変更ファイルを退避した内容へ戻し、測定が書き換えたパスのうち測定前に差分がなかったものだけを`git checkout`と`git clean`で戻す
4. 測定後のstatusが保存した内容と一致しない場合は、後続工程へ進まず差分と退避先をユーザーへ報告する
