# 完成条件や採否が依存する値の測定

本書は`agent-toolkit:add-awi-by-user`のセッションで、成果物の制限の例外として値を測定するエージェントへ、測定後に対象リポジトリの作業ツリーを測定前の状態へ戻す手順を定める。

## 測定の手順

1. 環境変数、引数、別の設定ファイルなど、追跡ファイルを変えない方法を先に使う
2. 追跡ファイルの変更が要る場合は測定前の`git status --porcelain=v1`と変更対象ファイルの内容を退避し、変更対象か測定が書き換え得るパスに既存差分があれば`git worktree add --detach`で作成した検証用worktreeで測定する
3. 元の作業ツリーで測定した場合は、変更ファイルを測定前に退避した内容へ戻し、測定前に差分の無かったパスだけを`git -c submodule.recurse=false checkout`と`git clean`で戻す。親だけを復元する呼び出しでは、初期化済みサブモジュールのHEAD・branch・作業内容を保持する
4. 測定後のstatusが保存した内容と一致しない場合は、後続工程へ進まず差分と退避先をユーザーへ報告する
