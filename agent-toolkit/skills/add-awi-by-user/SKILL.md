# AWI投入

本スキルはユーザーが手動起動したAWI登録の対話機能である。このセッションで編集できる成果物はWIの登録と更新に限る。対象リポジトリの実装、実装用worktreeの作成、AWIの`processing`への移動と実装担当の起動は、このセッションの対象外とする。
本スキルが担うWI作成工程の入力、責務および出口は`${CLAUDE_PLUGIN_ROOT}/share/workflow-phases.md`に従う。

## 手順

1. `agent-toolkit:wi-standards`と`agent-toolkit:writing-standards`を起動する。通常AWIの本文、起草完了条件、由来、投入と取得および保存確認は`agent-toolkit:wi-standards`だけに従って適用する。
   AWI本文の調査を委譲する場合は、委譲前に`agent-toolkit:delegation`を起動し、投入前に委譲先の終端を観測する。
2. `agent-toolkit:confirmation-and-uwi`の`references/grilling.md`を全文読み、認識の違いで要件や結果が変わる未確定事項がなくなるまで質問ラウンドを行い、同書の終了時報告を出力してからAWI本文を起草する。既に明示された要件と合意済みの要件は再確認の対象外とする。引数の無い起動で直前の応答が項目ごとの処置を確定した成果物を示す場合は、その成果物を登録対象の入力とし、示された確度や処置の基準を起草者が当てはめ、基準でも一意に決まらない項目と処置未確定の項目だけを質問する。直前にそのような成果物がない場合は、受領した依頼と成立済みの合意から対象を整理する。
3. 必要な認識合わせと本文の自動チェックを終え、複数本文では手順2で確定した判断に全本文の反映箇所または非該当理由が対応するかを`agent-toolkit:wi-standards`「投入と取得」に従って確かめる。起草完了の条件を満たし、対応を確かめた本文を`atk wi add`へ渡す。保存本文の一致確認は`agent-toolkit:wi-standards`「投入と取得」手順9の検収に従う。登録依頼は本スキルの起動時に成立しているため、本文の`less`表示、投入可否の一律質問、修正後の機械的な再承認を工程から外す。修正が新しい未確定要件を生じさせた場合だけ、手順2へ戻る。
4. 投入結果を`agent-toolkit:completion-report`へ渡して完了報告を生成する。

本スキルは協調モードで動作する。投入する項目の`source`は`add-awi-by-user`とする。ユーザー要求の逐語転記は`agent-toolkit:wi-standards`「由来と承認」に従う。

## セッション境界

成果物をWIの登録と更新へ限定する契約には、`agent-toolkit:confirmation-and-uwi`の`references/user-utterance.md`の成果物制限を適用する。主題の分類は、既存AWIを更新するか別のAWIを起草するかの判断だけに使い、その判断は`agent-toolkit:wi-standards`冒頭のAWIの粒度の基準に従う。完了報告後の追加要求にも同じ順序を適用する。
起動後の「反映して」「修正して」など、反映または修正を求める要求は、AWI本文への反映として扱う。再発防止と完遂の要求もAWI本文で満たす。成果物の制限から外れるのは、登録用一時入力の作成と管理CLIによる後始末、対象リポジトリの規範が同じ工程で要求する固有の追跡先への記載、および完成条件や採否が依存する値の測定と測定のための一時的な変更とする。測定は環境変数、引数または別の設定ファイルの指定で追跡ファイルを変えずに実施できる方法を先に使う。追跡ファイルの変更が必要な場合は測定前の`git status --porcelain=v1`を保存し、変更対象と測定が書き換え得るパスに既存差分があれば`git worktree add --detach`で作成した検証用worktreeで測定する。元の作業ツリーで測定した場合は変更ファイルを退避した内容へ戻し、測定が書き換えたパスのうち測定前に差分がなかったものだけを`git checkout`と`git clean`で戻す。測定後のstatusが保存した内容と一致しない場合は、後続工程へ進まず差分と退避先を利用者へ報告する。
制限を超える成果物の認可は`agent-toolkit/rules/01-agent.md`「完遂と先送り」に従う。委譲する場合は、起動スキル、WIだけを許す成果物制限、session終端を起動文へ含める。

## 完成条件

- 認識の違いで要件または結果が変わる事項の回答を投入前に得ている
- 必要な認識合わせと本文チェックを終え、起動時の登録依頼に基づく入力を登録している
- `agent-toolkit:wi-standards`が定める成功報告と警告の不在を確認している
- 対象リポジトリの実装と`processing`項目を起動時のまま保っている
