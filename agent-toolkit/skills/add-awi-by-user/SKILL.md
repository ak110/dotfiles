# AWI投入

本スキルはユーザーが手動起動したAWI登録の対話機能である。このセッションで編集できる成果物はWIの登録と更新に限る。対象リポジトリの実装、実装用worktreeの作成、AWIの`processing`への移動と実装担当の起動は、このセッションの範囲の外に置く。
本スキルが担うWI作成工程の入力、責務及び出口は`${CLAUDE_PLUGIN_ROOT}/share/workflow-phases.md`に従う。

起動後の「反映して」「修正して」その他の要求は、AWI本文への反映として扱う。再発防止と完遂の要求もAWI本文で満たす。成果物の制限から外れるのは、登録用一時入力の作成と管理CLIによる後始末、及び対象リポジトリの規範が同じ工程で要求する固有の追跡先への記載だけとする。

## 手順

1. `agent-toolkit:wi-standards`と`agent-toolkit:writing-standards`を起動する。通常AWIの本文、起草完了条件、由来、投入と取得及び保存確認は`agent-toolkit:wi-standards`だけに従って適用する。
   AWI本文の調査を委譲する場合は、委譲前に`agent-toolkit:delegation`を起動し、必要なツール、書込権限、完了通知、待機手段を候補手段の間で比較する。
   `agents_server`が必要な能力を満たす場合は調査と終端観測を同じ手段へそろえ、満たさない場合だけ不足する能力を記録して別の手段を選ぶ。
   手段を先に確定し、調査結果と完了通知を同じ観測先へ集めて投入前の完了判定を成立させる。
2. `agent-toolkit:plan-mode`の`references/grilling.md`を全文読み、認識の違いで要件や結果が変わる未確定事項がなくなるまで質問ラウンドを行い、同書の終了時報告を出力する。既に明示された要件と合意済みの要件は再確認の対象外とする。
3. 調査結果で正常な対象と変更を要する対象が混在する場合は、両者とAWIが変更する範囲を最初の1文で対照する。`欠陥`、`不足`、`未追随`その他の評価語には対象名を伴わせる。本工程は調査を完了した場合だけ適用し、全対象が同じ判定の場合と調査途中は対象外とする。
4. 依頼が対象集合の見直し、存廃、要否又は仕分けを求める場合は、投入前に対象を1件1行で列挙し、各対象の判定と根拠を本文の表へ確定する。種類別の方針や「不要なものを削除する」のような判定を処理担当へ委ねる記述は、判定の確定に当たらない。判定した対象の変更に連動して結果が変わる対の対象（その対象を前提とする規範条文、テスト、設定、登録、状態）を同じ調査で特定し、その判定も同じ表へ確定する。単一の対象を変更する依頼には本工程を適用しない。
5. 対象リポジトリの有効な規範が同じ工程へ求める追跡先とAWI本文形式（タイトルの接頭辞、参照行など）を確認し、本文へ反映する。追跡先への記載契機を規範が投入前又は検知時と定める場合は、その順序で記載する。判定は対象リポジトリの規範に従い、追跡先を定めない対象リポジトリでは確認と外部操作を追加しない。
6. 必要な認識合わせと本文の自動チェックを終え、複数本文では手順2で確定した判断に全本文の反映箇所又は非該当理由が対応するかを`agent-toolkit:wi-standards`「投入と取得」に従って確かめる。起草完了の条件を満たし、対応を確かめた本文を`atk wi add`へ渡し、保存された本文が渡した本文と一致することを確かめる。登録依頼は本スキルの起動時に成立しているため、本文の`less`表示、投入可否の一律質問、修正後の機械的な再承認を工程から外す。修正が新しい未確定要件を生じさせた場合だけ、手順2へ戻る。
7. 手順5で追跡先へ記載した場合はその記載が完了したことを確かめ、投入結果を`agent-toolkit:completion-report`へ渡して完了報告を生成する。

本スキルは協調モードで動作する。投入する項目の`source`は`add-awi-by-user`とする。ユーザー要求の逐語転記は`agent-toolkit:wi-standards`「由来と承認」に従う。

## セッション境界

成果物をWIの登録と更新へ限定する契約は、主題の分類より先にセッション全体へ適用する。主題の分類は、既存AWIを更新するか別のAWIを起草するかの判断だけに使う。別の対象名、追加関係を示す表現、「反映して」「修正して」「直して」などの動詞は、成果物制限を解除する根拠から外す。完了報告後の追加要求にも同じ順序を適用する。制限を超える成果物の認可は`agent-toolkit/rules/01-agent.md`「完遂と先送り」に従い、本スキルのセッションでは実装可否を質問する分岐を対象外とする。委譲する場合は、起動スキル、WIだけを許す成果物制限、session終端を起動文へ含める。

## 完成条件

- 認識の違いで要件又は結果が変わる事項の回答を投入前に得ている
- 必要な認識合わせと本文チェックを終え、起動時の登録依頼に基づく入力を登録している
- `agent-toolkit:wi-standards`が定める成功報告と警告の不在を確認している
- 対象リポジトリの実装と`processing`項目を起動時のまま保っている
