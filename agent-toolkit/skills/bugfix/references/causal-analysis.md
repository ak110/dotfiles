# 因果分析の品質基準

<!-- read-source: agent-basics:bugfix/references/causal-analysis.md -->

品質の定義元は`agent-basics:bugfix`の`references/causal-analysis.md`である。呼出元が指定した条件と読込範囲を、同名の正式な品質資料へ引き継ぐ。節指定がある場合は移設先の実見出しへ接続し、指定がない場合は従来の全文読込契約を保つ。取得済みの同版本文は再取得せず使う。

## 拡張原因分析の資料と因果の確定

品質の定義は`agent-basics:bugfix`の`references/causal-analysis.md`「拡張原因分析の資料と因果の確定」を適用する。

## 原因分析の段階

品質の定義は`agent-basics:bugfix`の`references/causal-analysis.md`「原因分析の段階」を適用する。
