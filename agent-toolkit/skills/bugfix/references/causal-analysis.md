# 因果分析の品質基準

<!-- read-source: agent-basics:bugfix/references/causal-analysis.md -->

品質基準の定義元は`agent-basics:bugfix`の`references/causal-analysis.md`である。呼び出し元が指定した条件と読み込み範囲は、同名の正式な品質基準資料へ引き継ぐ。節の指定がある場合は移設先の該当見出しを参照し、指定がない場合は資料全体の読み込みとして扱う。すでに取得済みの同一バージョンの本文がある場合は、再取得せずにそれを再利用する。

## 拡張原因分析の資料と因果の確定

品質基準の詳細は、`agent-basics:bugfix`の`references/causal-analysis.md`「拡張原因分析の資料確認と因果関係の特定」を参照して適用する。
