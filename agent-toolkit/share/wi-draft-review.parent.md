# 通常AWIの投入前レビュー

```text
起動対象: wi-draft-review.subagent.md
```

## 起動と受領

通常AWIを`atk wi add`へ渡すときは、本文の起草者と別の担当へ投入前レビューを1回依頼する。人間が原稿を渡した場合も対象とする。UWIは対象外とする。

同時に確定した複数本文は1件のレビュー起動へまとめる。本文をUTF-8のファイルへ保存する。原稿の対象、除外又は認可が確認回答に依存する場合は、回答に対応する質問、提示した全選択肢の全文、実際に選ばれた選択肢及び自由記述を、ユーザー原文を保持する同じ記録へ保存する。確認回答に依存しない原稿には追加の記録を求めない。`agents_server.start`の`subagent_md_path`へ`${CLAUDE_PLUGIN_ROOT}/share/wi-draft-review.subagent.md`の絶対パスを渡す。`extra_params`の`レビュー対象`へ原稿ごとに本文ファイルと対象リポジトリの絶対パスを渡し、人間由来の要求がある原稿には原文記録の所在も対応付ける。レビュー担当には読取専用の起動条件を使い、投入操作を委ねない。
`extra_params`の`引き継ぎ記録先`へ、セッション領域（`agent-toolkit:managed-temp`）の直下に置く記録ファイルの絶対パスと`（新規）`を渡す。

担当から本文ごとの`採用`、`修正`、`取り下げ`と理由を受け取る。投入する主体は`agent-toolkit:review-standards`の`references/reviewee.md`に従って指摘の妥当性を判断し、必要な修正または取り下げを反映してから投入する。修正後の再レビューを自動で繰り返さない。結果と処置を、投入を行う主体の引き継ぎ記録へ残す。
