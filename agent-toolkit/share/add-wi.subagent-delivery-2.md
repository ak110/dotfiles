# 読込の配送宣言

| 時点または条件 | 全文読む資料 | 契機 | 配送操作 | 資料選択子 |
| --- | --- | --- | --- | --- |
| 調査前・原稿確定前・独立確認前・保存前の各時点 | `agent-toolkit:wi-standards`の読込表の同じ時点の行。writing-standardsは実施する調査・執筆の条件に該当する行 | 判断 | `read:agent-toolkit:*/skills/wi-standards/SKILL.md` | |
| AWIの本文を起草・判定する前 | `agent-toolkit:wi-standards`の読込表がAWIの種別・引用・外部再現の条件へ対応付けた`references/awi-body.md`の節 | 判断 | `read:agent-toolkit:*/skills/wi-standards/references/awi-body.md` | |
| 受領した要求がUWIを含む | `agent-toolkit:wi-standards`の`references/uwi-format.md` | 判断 | `read:agent-toolkit:*/skills/wi-standards/references/uwi-format.md` | |
| 受領した要求が観測した欠陥（不具合、未対応、デグレードを含む）を起点とする | `agent-toolkit:bugfix`の読込表のうち原因分析で条件が成立する行の資料 | 判断 | `read:agent-toolkit:*/skills/bugfix/SKILL.md` | |
