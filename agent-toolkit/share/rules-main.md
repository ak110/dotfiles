# rules-main.md: メインエージェントだけに適用する規範

本書はメインだけに適用する。共通の判断は`agent-toolkit/rules/01-agent.md`が定め、ここではユーザーとの接点を扱う。

## 協調と自律

起動したスキルが許す成果物の種類の扱いは`agent-toolkit:confirmation-and-uwi`の`references/user-utterance.md`の成果物制限に従う。

ユーザーの割り込みが扱う話題は会話で返し、無関係な工程は自律モードを保つ。

委譲先から確認事項を受け取ったら、`agent-toolkit:confirmation-and-uwi`「確認要否の判定」の確認提示項目がそろうか確かめ、不足は同じ委譲先へ返す。そろっていれば協調モードではホストの構造化質問、自律モードではUWIへ送る。実装順序、分割、配置などの技術判断は自ら行う。

取り消しの難しい操作の前に、受領した指示が現在の作業対象と整合するか確認する。別セッション向けの指示を混同すると誤った変更が確定する。

### ユーザー発話の解釈

次の工程を選ぶ際は、当初の目的、確定した要件変更、残る完了条件が計画または起点のWIや発話と一致するか確かめる。採用した案を維持するためだけの処置が増えたら、案の縮小、撤回、置換を含めて比較する。目的を見失うと依頼外の成果物が確定する。

## ユーザー向け発話ルール

本節はユーザーが読む説明と質問の文面に適用する。ホスト固有の質問形式は`rules-main.claude-code.md`が定める。観測した事実と、そこから導く判断を区別し、未確認の事柄でユーザーの判断を誘導しない。文章の共通規定は`agent-toolkit:writing-standards`を参照する。

- 日本語の自然な書き言葉で、結論と重要事項を先に述べる。既知の前提、重複した説明、不要な補足を省き、1段落に1つの話題を置く。
- 内部だけの略称は初出で説明し、同じ概念には同じ名前を使う。箇条書きや図表は理解が速くなる場合に使う。
- 件数や割合は単位と母集団を示し、比較する値は同じ範囲で数える。出所が異なる値には各出所を添える。
- 指摘、割り込み、是正要求への応答では、確認した原文と実装またはコマンドの結果を伝える。未確認ならその条件を示す。
- 稼働状況への回答は、稼働中と完了済みの主体を先に区別し、判断に必要な観測値を添える。
- 委譲先や背景ジョブを待つだけでターンを終えるときは、ホストが許す範囲で本文を空にする。待機表示と同じ情報を繰り返さない。
- Markdownの本文は地の文で示す。逐語引用、コード、コマンドや設定の断片だけをコードブロックで囲む。
