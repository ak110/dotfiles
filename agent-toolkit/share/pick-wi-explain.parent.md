# 選定理由の説明担当の起動と受領

```text
起動対象: pick-wi-explain.subagent.md
```

処理対象WIについて、包含、除外または構成の理由をユーザーが尋ねた場合に、メインが本書に従って読み取り専用の説明担当を起動し、結果を受領する。
説明担当の手順は`${CLAUDE_PLUGIN_ROOT}/share/pick-wi-explain.subagent.md`が定める。

## 起動

メインの選定工程が終わっていても、読み取り専用の説明担当を起動する。
説明担当は`atk`を起動できないため、起動の前に`atk wi show --all --target-repo=<元の選定対象リポジトリの絶対パス> --state=active --skip-pull`を実行し、返った`保存先:`の絶対パスを受領まで保持する。

`agents_server`の`start`を次の引数で呼ぶ。

| 引数 | 値 |
| --- | --- |
| `cwd` | 元の選定対象リポジトリの絶対パス |
| `subagent_md_path` | `pick-wi-explain` |
| `extra_params` | 次の名前付き入力だけ |

- `説明対象の選定結果の出力先ファイル`: 元の`pick-wi.yaml`の絶対パス
- `activeなWI本文の保存先`: 起動の前に実行した`atk wi show`が返した`保存先:`の絶対パス
- `選定理由への質問`: ユーザーの問い

## 受領

返した`session_id`を`atk agents wait`で観測し、説明担当の結果から対象WIごとの規定上の根拠、技術的必要性、process-wiの同じ実行の中で扱う案と次の実行へ送る案のQCD比較、および推論の区別を検収してユーザーへ伝える。規定への適合だけを結論にしない。
規定の欠陥が判明した場合は処理対象WIを変更せず、メインが`agent-toolkit:bugfix`に従って同じセッションで是正する。
受領時に起動の前と同じ`atk wi show`を実行し、新しい保存先と起動時の保存先の`### <ファイル名> [<状態>]`の見出しを比べてWI状態の前後を確かめる。
WI状態の変化を観測した場合と、元の選定結果またはレーン割当が変化したと報告された場合は、比べた前後の値と説明担当が記録した前後の値を確認し、変更を説明の成果とみなさず変化した主体と影響を調べる。固定済みの選定集合は質問への回答を通じて維持する。
