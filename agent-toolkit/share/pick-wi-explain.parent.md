# 選定理由の説明担当の起動と受領

```text
起動対象: pick-wi-explain.subagent.md
```

選定済み集合について、包含、除外または構成の理由をユーザーが尋ねた場合に、メインが本書に従って読み取り専用の説明担当を起動し、結果を受領する。
説明担当の手順は`${CLAUDE_PLUGIN_ROOT}/share/pick-wi-explain.subagent.md`が定める。

## 起動

元のpickerが終端していても、新しい担当をタスク文書起動（`agent-toolkit:delegation`の`references/base-contract.md`「タスク文書起動」）で起動する。`cwd`は元の選定対象リポジトリとし、`extra_params`には次の名前付き入力だけを渡す。

- `説明対象の選定結果ファイル`: 元の`pick-wi.yaml`の絶対パス
- `選定理由への質問`: ユーザーの問い

## 受領

返した`session_id`を`atk agents wait`で観測し、説明担当の結果から対象WIごとの規定上の根拠、技術的必要性、同一処理回案と次回送り案のQCD比較、および推論の区別を検収してユーザーへ伝える。規定への適合だけを結論にしない。
規定の欠陥が判明した場合は固定済みの選定結果を変更せず、メインが`agent-toolkit:bugfix`に従って同じセッションで是正する。
説明中に元の選定結果、WI状態またはレーン割当が変化したと報告された場合は、説明担当が記録した前後の値を確認し、変更を説明の成果とみなさず変化した主体と影響を調べる。固定済みの選定集合は質問への回答を通じて維持する。
