# 投稿前レビュー担当の起動と受領

```text
起動対象: external-write-review.subagent.md
```

`agent-toolkit:external-write-review`の対象となる文面を投稿するエージェントが、本書に従って投稿前レビュー担当を起動し、結果を受領する。
レビュー担当の観点と返却形式は`${CLAUDE_PLUGIN_ROOT}/share/external-write-review.subagent.md`が定める。

## 起動

確定した文面をUTF-8のファイルへ保存してから、1件のレビュー担当を起動する。

`agents_server`の`start`を次の引数で呼ぶ。

| 引数 | 値 |
| --- | --- |
| `cwd` | 文面が根拠とする対象リポジトリの絶対パス |
| `subagent_md_path` | `external-write-review` |
| `extra_params` | 次の名前付き入力だけ |

- `文面ファイル`: 文面ファイルの絶対パス
- `投稿先と目的`: 投稿先と投稿の目的
- `根拠の所在`: 文面が根拠とする差分・観測結果・関連ファイルの所在

行数の事前提供は要しない。行数付きの入力も渡せる。必要な行数は読む担当が実体から取得する。
委譲先として投稿するエージェントも、同じ担当内の独立した確認として本書に従って起動する。

## 受領

結果は引数なしの`atk agents wait`で受け取り、起動したsessionの終端を確認する。
指摘の採否は`agent-toolkit:review-standards`の`references/reviewee.md`に従って確定し、採用した指摘を文面へ反映してから投稿する。
レビューは投稿前に1回実施することを原則とする。反映後の再レビューは費用を増やすため自動では繰り返さず、反映によって事実主張や対象範囲が変わった場合は、外部公開前の確認が不足しないよう再レビューの要否を判断する。

起動したsessionが結果を返さずに終端した場合は、同じ入力で1回だけ起動し直す。
再度結果を得られない場合と、`start`を起動できず同等の読み取り専用の委譲手段も利用できない場合は投稿を止める。
原因と同等のレビュー手段を調べ、認可内で回復できれば自ら再開する。失敗回数だけでは確認せず、`agent-toolkit:user-confirmation-and-report`「確認要否の判定」で、レビュー省略や公開結果の変更に必要な追加認可・選好が残る場合だけ文面と理由を示して確認する。
