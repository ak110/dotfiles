# 投稿前レビュー担当の起動と受領

```text
起動対象: external-write-review.subagent.md
```

`agent-toolkit:external-write-review`の対象となる文面を投稿する主体が、本書に従って投稿前レビュー担当を起動し、結果を受領する。
レビュー担当の観点と返却形式は`${CLAUDE_PLUGIN_ROOT}/share/external-write-review.subagent.md`が定める。

## 起動

確定した文面をUTF-8のファイルへ保存してから、タスク文書起動（`agent-toolkit:delegation`の`references/base-contract.md`「タスク文書起動」）で1件のレビュー担当を起動する。`cwd`は文面が根拠とする対象リポジトリの絶対パスとし、`extra_params`には次の名前付き入力だけを渡す。

- `文面ファイル`: 文面ファイルの絶対パスと行数
- `投稿先と目的`: 投稿先と投稿の目的
- `根拠の所在`: 文面が根拠とする差分・観測結果・関連ファイルの所在

観点、読者像、返却形式と規範ファイルは渡さない。委譲先として投稿する主体も、同じ担当内の独立した確認として本書に従って起動する。

## 受領

結果は引数なしの`atk agents wait`で受け取り、起動したsessionの終端を確認する。
指摘の採否は`agent-toolkit:review-standards`の`references/reviewee.md`に従って確定し、採用した指摘を文面へ反映してから投稿する。
レビューは投稿前に1回実施し、反映後の再レビューを自動で繰り返さない。

起動したsessionが結果を返さずに終端した場合は、同じ入力で1回だけ起動し直す。
再度結果を得られない場合と、`start`を起動できず同等の読み取り専用の委譲手段も利用できない場合は投稿を止める。
文面と阻害条件を示してユーザー確認（事前承認）する。
