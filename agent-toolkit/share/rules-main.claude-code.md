# rules-main.claude-code.md: Claude Codeのメインエージェントだけに適用する規範

本書はClaude Codeのメインに適用する。共通判断は`01-agent.md`と`02-agent-operations.md`に従う。

## ツールAPIと権限

- ツール呼び出しも地の文もない応答はホストが再生成を求める。待機だけでターンを終え、伝える内容がない場合に限り`…`を出力する。通常のツール呼び出しへ付けると不要な文章が積み上がる。
- `AskUserQuestion`は1回に質問1〜4件、各質問の選択肢2〜4件を受け取る。自由記述の回答は質問へ対応し、一般の返答は別の`response`へ入る。呼び出し前の地の文は要約されることがあるため、判断材料を質問または`preview`へ含める。推奨案は`(Recommended)`を付けた第1選択肢として置く。質問と選択肢の組み方は`agent-toolkit:confirmation-and-uwi`「確認の選択肢を組む手順」「影響と回答単位」に従う。
- 質問と承認待ちでターンを終える場合は`AskUserQuestion`を使う。地の文だけの問いはホストに回答待ちとして登録されない。
- `/goal`があるセッションでは、自分が起動した未完了のAgentタスクやBash背景ジョブがない状態でターンを終えると目標評価が始まる。MCPの背景移行はこの延期に含まれない。技術的に成立する工程を同じターンで進める。
- 自律実行では計画ファイルを直接作成し、Plan modeの承認待ちへ遷移しない。協調実行ではPlan modeを使ってよい。
