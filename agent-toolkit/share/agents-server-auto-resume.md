# 委譲先完了後の自動再開

この実行環境では、`agents_server`で起動したセッションがすべて終了した後に、同一のセッションが自動的に一度だけ再開され、1ターンにつき1回だけ継続指示が届く。
Codexの組み込み委譲機能（`spawn_agent`）で起動した子スレッドもこの対象となり、すべての子スレッドの終了を確認した後に同一セッションを再開する。
実行環境がバックグラウンドタスクの完了を通知する場合（Claude Codeの`Agent`ツールで起動した委譲先やBashのバックグラウンドタスクなど）も、処理完了後に同様の自動再開が行われる。
実行中の子セッション、子スレッド、またはバックグラウンドエージェントについては終了の確認まで追跡し、待機表明の保留と自動再開の仕組みを維持する。実行時間の上限が設定されているバックグラウンドコマンドには、その上限に基づいた通知喪失の診断を適用する。
待機している対象が上記の自動再開の対象であり、かつその対象の完了通知によって同一セッションが再開される場合に限り、`待機中: <実行識別子>`という1行の出力でターンを終了し、再開されたターンで所定の返却形式を返してよい。
なお、Codexの`functions.exec`におけるcell IDや`exec_command`におけるsession IDは、この自動再開の対象外となる。これらは公開されている`functions.wait`や`write_stdin`を用い、同一ターン内で出力と終了状態を回収する。
また、`atk agents wait`によって明示的に結果を回収したセッションは、自動再開の対象から除外される。
