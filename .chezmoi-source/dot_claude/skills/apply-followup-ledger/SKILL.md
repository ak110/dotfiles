# 追従台帳の未適用項目を適用する

このスキルはユーザーが明示的に起動したときだけ使う。
対象はユーザーが指定したプロジェクト（指定がなければ現在の作業ツリー）とする。
届く姉妹プロジェクトへは追従AWIで適用する。
本人が明示的に起動する場合は手動適用もできる。
このファイルと同じスキル格納先にある `operate-ak110-projects/references/followup-procedure.md` を読み、「適用する手順」を実行する。
