# 方針・意向: 付帯作業

## 付帯作業の単位

実行時に適用する一般則は`agent-toolkit/share/rules/common/01-agent.md`「QCDと3段判定」、plugin規範の例外は`.claude/skills/agent-toolkit-edit/SKILL.md`「付帯作業の扱い」にある。

変更から生じた付帯作業は、関連開発と同じ計画、WIおよびcommitで完了する。
実装中に判明した整理も同じ工程で扱い、開発完了後の振り返りが独立に発見した作業は別の作業とする。

dotfilesリポジトリ内のagent-toolkit規範文書は、agent-toolkitユーザーへ届く成果物そのものを構成する。
この改訂は主作業として変更目的ごとにcommitとWIを扱う。
agent-toolkitのコードのリファクタリング、テスト、CIおよびコメントの整備には一般則を適用する。
例外は規範文書だけを主作業とするユーザーの判断に基づく。
2026年10月5日のユーザー指示（本節の冒頭の段落）が、まとめる義務を設けない扱いと、他の開発が必要にした規範文書の改訂を主作業とする扱いを置き換えた。

### 経緯（付帯作業の単位）

2026年9月29日の方針（まとめる義務は設けない）は2026年10月5日に置き換えた。
置き換える前の記録は次のとおりである。

リファクタリング、規範文書の改訂、CI、テストコードやコメントの整備などは、関連する開発と同じcommit、WIまたは計画へまとめてよい。
まとめる義務は設けず、関連する開発が無いときは単独の作業として扱える。
ユーザーは開発のついでに行う作業として整理することを求め、名称は「付帯作業」を選んだ（2026年9月29日）。
