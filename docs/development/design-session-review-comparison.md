# 比較材料と未確認範囲の設計記録

[設計記録の索引](design.md)と[振り返り・知見集約の設計記録](design-session-review.md)から参照する主題別の記録である。

成功した作業の比較材料は、異常候補と分けて既存の収集記録から生成する。
bundleの`comparison-materials.jsonl`が委譲入力・明示読取・命令文字列だけの観測を区別し、prepareが別文書`comparison-materials.md`の概要から全文位置へ接続する。
会話の流れに比較材料を連結する構成は、メインの時系列と記録別の参照資料を混ぜ、通読の量を増やしていたため分けた。
比較材料は記録別見出しで示し、記録をまたぐ時系列ではないことを冒頭に明記する。
prepareは会話の流れのUTF-8量と原則上限100,000バイトを返す。
100,000バイトは特定のユーザー発話量によらず、実ユーザー発話が0件の自律モードにも適用する。
今回の実ユーザー発話21件は約10KBで、その3〜5倍が約30〜50KBだったことを、100KB以下で全体像を保持できる比較材料とした。
採らなかった案は次のとおりである。
全文の展開を維持して分担の規定だけを詳しくする案は、全体像を分断し、量に比例する所要時間と利用枠の消費を残す。
担当の返却だけを一次資料にする案は、委譲先の操作量と失敗を通読から外す。
候補だけを通読の起点にする案は、候補抽出が持つ観点へ探索を限定する。
会話と比較材料の全体を、記録の境界を保つ部分ファイルへ分ける案も採らない。
読取単位はそろうが、根拠記録で読む量の94%だった参照用材料を通読へ残し、会話の複製も生むためである。
独自の行数計算は準備のたびに同じ後加工を生み、全資料の連結は時系列の判断を難しくするため採らない。
材料を候補へ混ぜる案も、正常操作の比較を異常の標識へ従属させるため採らない。
ファイル参照は本文量として数えず、入力の直接本文量と記録の結果本文量だけを観測した量として示す。
自動配送や読了を推定せず、対象・担当・時点を目的と比べる意味判断はメインへ残す。
セッション統計はメインと全担当の原始token内訳・cache・応答回数と定義を示し、Codexの総入力とcacheの内包関係を保つ。
非律速担当も品質・費用の比較から照会できる。
比較観点はanalysis.mdに集約し、全範囲の先行確認と列挙外の探索を続ける。
成功した作業の準備・検収・後始末・値の転記・工程境界と離れた区間の反復も、守る成果と要求元へ対応付けて簡略化を比べる。
短い操作の適用頻度と入力の組み直し、保守の費用は律速順位や300秒目標で除外しない。
既存の通読と詳細照会で扱い、正常操作の全台帳・監視・常設担当を新設する案は恒常費用が増えるため採らない。
正常な操作を自動的に欠陥候補へ加える案は、必要な調査と不要情報を量だけでは分けられないため採らない。

JSONLの読込境界はI/O・UTF-8・JSONの失敗を読取不能へ統一する。
単一照会は対象と次の操作を示す終了2、集合照会は正常結果と、読取不能の`unresolved-record`・親子関係を解決できない`unresolved-delegation`および未解決件数を返す。
Claude付随記録の失敗も兄弟の収集を継続し、カタログの通常表示と呼出照会の双方へ未確認範囲を渡す。

準備の未確認範囲は、bundleが標準出力へ返した`unresolved-record`と`unresolved-delegation`を準備の境界で取り出して共通で渡す。
候補文書・統計文書・1行JSONの集合をそろえ、候補件数や必須候補から分離する。
保存済みの走査全量を標準出力へ重ねる案と、メインに抽出の再実行を求める案は、それぞれ出力量と通常の往復を増やすため採らない。

失敗署名の台帳は代表イベントに同じ記録位置のhook通知の`text`・`hook_name`も保存し、読込時に抽出と同じ分類を適用する。
hook通知が表す失敗と、hook通知へ置き換える失敗を計数と書き戻しから除く。
通知欄を持たないイベント付き記録は、本文から判定できる置き換えを適用し、同じ位置の通知による除外は判定せず期限で回収する。

失敗署名の診断は、引用された理由・JSONのキー・意味のある数値と16進表記を残し、パス・UUID・記録IDと認識できる変動値だけを一般化する。
候補と過去30日の台帳は同じ正規化を使う。
判定に使う欄を持たない旧形式の記録は除外を判定し直せないため、保存済み代表診断から署名だけを再計算して数え、30日の期限で回収する。
最上位セッションと観測時刻は保ち、再準備で同じ署名・セッションの数を増やさない。
保存されなかった診断を復元する全過去ログの走査や、コマンドごとの例外一覧は加えない。
