# 方針・意向: Codexの文脈長

## Codexの文脈長設定

この設定を変える判断は`agent-toolkit:wi-standards/references/drafting-completion-policies.md`「方針と判断の記録との比較」の手順で本節と比較する。
実行時の設定は`.chezmoi-source/dot_codex/modify_private_config.toml`が`model_context_window=1000000`と`model_auto_compact_token_limit=900000`を固定する。
目的は、頻繁な自動圧縮による待ち時間と作業の進行阻害を避けることである。
2026年10月9日のユーザーの明示的な復元要求で導入し、10月23日に削除した。
2026年11月1日の次のユーザー指摘を受けて復元した。

```text
あとcodexのコンテキストが足りないならconfig.tomlで拡張した方がいいのでは？明らかにそこの問題で進行が阻害されてるじゃん。
```

- この2値を減らす、またはモデルの標準へ戻す変更は、別の改善で圧縮の頻度と待ち時間が許容範囲に下がることを、実作業の記録で観測してから行う。
  設定の生成結果とテストの一致は、この目的の達成を表さない。
  10月23日の削除は「別の改善である程度改善されるなら減らすかデフォルトにする余地は無いか」という条件付きの問いを、条件を観測しないまま採用したものだった
- 設定値はCodexへの宣言であり、モデルが実際に受理できる上限とは別である。
  100万トークンの実受理やモデル能力の変更は保証しない
