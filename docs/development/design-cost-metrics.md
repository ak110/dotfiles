# 手動の週次費用指標の設計記録

[設計記録の索引](design.md)と[振り返り・知見集約の設計記録](design-session-review.md)から参照する主題別の記録である。

## 手動の週次費用指標

`atk run-script cost-metrics`は費用改善の効果判定と再悪化の検知に使う、永続状態を持たない手動の集計コマンドである。
必要な時の実行で比較材料を得られるため、process-wi・review-sessionの工程や定期起動へ組み込むことはしない。
更新時刻が期間開始より前の記録を読込前に除き、記録の本文はルートごとの収集区間だけ保持する。

トークンの母集団は開始時刻が期間内のルートセッションであり、委譲先全体をルートの開始週へ帰属させる。
記録間の参照は既存の抽出、再帰収集は`_collect_records`、値の集計は`_stats_summary_data`と`_codex_normalized_tokens`、process-wiの判定は`_workflow_evidence`を使う。
任意の記録ディレクトリを指定できるよう、収集関数は省略可能な探索関数を受け取り、指定しない呼出しは既存の探索を使う。
runtimeをまたぐ記録の実体パスを集合で管理し、同じ記録を1回だけ加算する。

hook通知も同じルートと全委譲先を母集団とし、ルートの開始週へ帰属させる。
`cost-metrics-hook-notice`は週・runtimeと既存のhook通知分類（`hook`、`hook_name`、`tag`、`kind_text`）ごとの件数を返す。
hook実行の記録とツール結果だけにある遮断の抽出は、`session_evidence_hook_notices.py`へ集約し、`--hook-notices`・`--warn`・週次集計で共有する。
格納位置とエラー形式からhook出力を識別することで、通常の標準出力に引用された標識を除外する。
同じ呼び出しのhook記録と結果は重複除去し、並列実行の別々の遮断は要素ごとに数える。
既存の分類と母集団を共有する構成により、照会ごとの分類規則と新しい永続状態を増やさずに週別の増減を確認できる。

採用AWIはprivate-notesのGit履歴で採用状態へ変わった時点を、現行のfrontmatterと旧状態別配置の契約から判定し、同名ファイルを週内で重複除去する。
初出から採用済みのAWIも数え、採用状態を保つ配置移行と本文編集は新たな採用に数えない。
保存済みのレビュー表は最初の追加commitの週へ割り当て、`read_rows`がデコード・互換変換したexec-reviewの行から集計する。
不採用の判断主体と移管先は応答本文の行頭ラベルで明示し、記録定義側の解釈を採否と費用の両集計で共有する。
移管は独立した状態として数え、修正なし比率の分子から除く。
旧表の自由文から主体を推定する案は、担当の技術判断をレビュー担当の撤回と取り違えるため採らず、判断主体不明として保持する。
共通の保存表取得が明示的な実装中の判断記録を区別し、採否と週次の指摘件数・level・修正なし比率から除く。
判断記録だけの表でも期間とモデルの帰属に使う表情報を保持し、除外件数と表・行の所在を両集計へ渡す。
保存表を書き換えたり、生成側へ新しい必須行種別を追加したりせず、明示されていない判断記録を完全には識別できない限界を残す。
担当が自分で足す行（実装中の判断、完成条件の変更・除外の判断、統合時の競合解消）の書き出しは`agent-toolkit/share/review-table-operations.md`「レビュー指摘管理表の共通操作」の1箇所で定め、集計は指摘箇所の列がその書き出しで始まる行を同じ区別へ入れる。
規範の現物から書き出しを取り出す試験で、規範と集計の一致を確かめる。
列や`track`の値を足す案は、過去表の移行と全生成側の変更を要するため採らない。
実行レビュー担当の記録は、最初のモデル出力より前のuser役割の入力本文にある役割標識で見分ける。
記録の先頭から固定のバイト数を読む方式は、依頼文より前に置かれる道具の定義や規範の配送が増えると依頼文へ届かず、表を黙ってモデル不明に数えたため採らない（2026年11月11日の観測で、今回の期間72表中58表が不明だった）。
記録の全文から標識を探す方式は、標識を引用しただけの会話をレビュー担当の記録と数えるため採らない。
期間の集約をsession-review-evidenceの照会modeへ混ぜる案は、キュー履歴とレビュー表という別の入力と責務を加えるため採用しない。
トークンとレビュー表の読込を別実装にする案も、既存の正規化と互換処理の改訂が届かなくなるため採用しない。
