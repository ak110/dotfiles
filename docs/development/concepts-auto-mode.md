# 方針・意向: auto modeと許可

## auto modeと許可ルール

- auto mode classifierの拒否後に、ユーザー承認なしで同一操作を再発行する許可と手順を廃止する。
  偽陽性と判断できる最初の拒否から、`agent-toolkit/skills/user-confirmation-and-report/references/permission-denial.md`の確認へ進む。
  メインの操作と委譲先から受領した拒否に適用し、偽陽性の明示回答を受けた後の実行は維持する。
  同じ操作の反復がサーバー側に攻撃的な挙動と見なされるリスクを避けるというユーザーの判断によるもので、実際に攻撃判定されるという技術的事実を示すものではない
  （2026年10月7日、ユーザー指示）。
  旧許可は通常の設定反映で既存設定からも除く
- Claude Codeの確認ダイアログはPermissionRequestフックで無条件に許可し、許可した要求の記録だけを残す
  （2026年9月、ユーザー指示。auto modeでの運用を前提とし、承認の往復を無くすことを優先する）
- 偽陽性として承認した操作を実施したメインは、同種の承認の反復を減らす処置を検討する。
  環境固有は配布sourceの有無によらず`~/.claude/settings.json`へ直接追記し、汎用はdotfiles作業中も管理原本を直接編集せずdotfiles向けAWIへ渡す。
  明らかな一時条件と再発しない根拠がある場合だけ対処なしとする。
  処置の要否と省略の可否は2026年10月10日のユーザー指示により`agent-basics:bugfix`の`agent-basics:bugfix/references/root-cause-severity-impact.md`「QとC・Dの区別」で判定する。
  承認済みの操作種別・拒否区分・副作用区分を広げる場合だけ追加確認し、再発防止の処置より承認済み操作の実施を先行させる
  （2026年10月9日、ユーザー指示）。
  読み手は偽陽性承認後の判断をするエージェント、適用範囲は`hard_deny`の外である。
  通常のsource優先の編集先判断よりこの分類を優先する。
  文面・包含・独自追記・取消方法・実効化の手順は`agent-toolkit/skills/user-confirmation-and-report/references/permission-denial.md`の手順6が持つ
- auto modeの許可ルールは、操作の種別と除外条件で対象を決める。
  remoteのホスト、由来（AWI処理かどうか）および所有者による限定は条件として置かない
  （2026年9月17日、ユーザー指示。「現状のプロンプトが全体的に禁止事項が多すぎるのでいっそもっと全体的に緩和して統一感を持たせてほしい」）。
  PR/MRのマージ許可もこの方針に含め、remoteのホストで限定しない。
  2026年9月16日のAWIは、信頼境界宣言との整合を根拠にマージ許可を`github.com/ak110`配下へ限定した。
  しかし、その限定はユーザーの意向と異なる。
  以降の限定の再導入は、新しいユーザーの判断からだけ行う
- auto modeの許可ルールの文面は、変化しやすい識別子（サブコマンド名、オプションの完全な綴り、個別ファイルのパス）を列挙せず、操作の種別で書く
  （2026年9月17日、ユーザー指示。「キュー管理サブコマンドとかはころころ変わるから列挙しないでほしい」）
- エージェントが自ら作成したtmuxセッションで対話CLIを起動し、キー入力の送信と画面の取得で検証する操作は、許可ルール`Session And Delegation Control`の対象とする
  エージェント自身のpane操作と、ユーザーが作成した既存セッションの操作は対象に含めない。
  これらにはこの許可ルールを適用せず、auto modeのclassifierが他のルールで行う判定に委ねる
  （2026年9月30日、ユーザー指示。検証の送信操作が`Tmux Self Drive`で拒否された観測に由来する）

  この項目の出典となったユーザーの発話は次のとおりである。

  ```text
  あとtmuxを使った検証は今後も自動でやってほしいので許可ルールの追加もAWI投入してほしい
  ```

- エージェント、その委譲先、起動したテスト・スクリプト・ツールの誤操作が変更した範囲を記録された変更前の値へ戻す操作は、許可ルール`Agent Mistake Recovery`の対象とする。
  置き場所と共有の有無を問わず、ユーザーの承認を待たない
  （2026年10月4日、ユーザー指示。「エージェントが間違えたものを戻すのは自動でやってもらわなきゃ困る」「share\\claude_settings_json_managed.jsonに追記して」）
