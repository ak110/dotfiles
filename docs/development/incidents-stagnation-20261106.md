# 障害・欠陥の記録: 停滞と空転（2026年11月6日〜）

[停滞と空転](incidents-stagnation.md#停滞と空転)の事例を発生時期別に収録する。

- 2026年11月12日: 統括が巡回の途中で是正のAWIを追加しようとした`pick-wi-check --merge`が、全工程の見込みが無いことを理由に終了コード1で拒否され、正式な追加の手順を使えなかった。
  巡回は開始から19時間を超えており、見込みを入れても目標超過で拒否される状態だった。
  直接原因: 選定検査が、見込みの欠落、未確認前提、目標超過を終了コード1とし、追加mergeにも見込みの再確定を求めていた。
  いずれも経過時間と観測待ちに由来し、検査を渡した担当がその場の入力で解消できなかった。
  背景原因: 解消できない条件でblockしない方針がhookの規範にだけあり、検査・CLIの判定の設計規範とレビュー観点に届いていなかった。
  対策: 見込みに関する3判定と追加mergeの見込み必須を警告へ改め、レーン数の上限などその場で直せる違反は拒否のまま残した。
  対策: `design-heuristics-mechanisms.md`「進行を止める判定の条件」を置き、初回レビューと規範追記時の判定にその確認を加えた。
