## 識別子・言語仕様・運用契約の検証

- 2026年7月: 完了報告のコミットSHAが1文字誤っており、存在しないSHAへのCI通過待ちを約10分継続した。
  直接原因: 報告値を確認せず後続コマンドへ渡した。
  対策: 識別子は実行結果の値をそのまま使い、短縮形からの復元・記憶で組み立てない

- 2026年7月: Python 3.13/3.14で合法な構文（`except (A, B):`・PEP 758）を旧構文と誤判定した重大誤指摘が複数回発生。
  直接原因: レビュー担当が対象言語バージョンの仕様を確認せず学習知識だけを根拠に言い切った。
  対策: 言語バージョン確認とレビュー指摘採用前の一次資料での確認を義務化

- 2026年8月27日: review-sessionで、未完了作業へのユーザー介入を観測したにもかかわらず、メインが長時間待機後に既存規範・重複・過剰設計を先に評価し、「提案無し」で終了した。
  直接原因: 原因と既存対策の有効性を確定する前に抑止判定を行った。
  対策: 原因分析・類似見直し・三層処置・根本原因単位の被覆を抑止判定より先に確定し、契約テストで4原因区分、三層処置、部分被覆、全被覆と最終報告の根拠を検証する。
  advisorの問題列挙専任契約は維持する

## 要求と判断の脱落

- 2026年9月8日: 「抜本的に手順やスクリプトを見直して大幅な高速化を達成できるようにしてね」という改善効果の指定を受領した後も、局所の不具合の調査が先行し、現行構造を維持する案と変更する案の比較が行われなかった。
  直接原因: 改善効果を採用案の受入条件として先に確定し、個別調査を構造の維持案と変更案を比較する設計判断に結び付ける規定が無かった。
  対策: `agent-basics:review-standards`の`references/reviewee.md`へ改善効果を指定する要求の扱いを新設し、受入条件の確定と維持案・変更案の比較を個別調査より先に置く

- 2026年9月9日: 依頼した成果へ到達する前に部分結果を示し、続行の可否をユーザーへ質問して工程を停止する応答が繰り返された。
  直接原因: `agent-toolkit/rules/01-agent.md`「完遂と先送り」が`AskUserQuestion`の回答待ちと承認待ちを無条件の例外とし、例外を適用する際に質問が同ファイルの確認要件を満たすか判定させていなかった。
  対策: 「協調と自律」、「確認を要する事項」、適用中のスキルのいずれかが定める条件を満たす確認に限り、質問待ちと承認待ちを例外として扱う。
  依頼と成立済み承認の範囲の内側にある実行可能な未完了工程は、続行可否を確認へ変換せず同じターンで継続する

- 2026年9月21日: 確認、AWI投入、終了判定および検証通知で、既存の分類や状態値を先に適用した結果、ユーザーが示した要件と未回収の結果が工程から脱落した。
  直接原因: 発話原文と成果物種別の境界を分類より先に保持する契約、未回収結果を継続中とする共通判定、用途別の具体的な修復案が直接消費側へ届いていなかった。
  対策: 原文保持と優先順位判定をユーザー確認の前段へ置き、AWI専用境界を主題分類より先に適用する。
  未回収のagents_server結果をStop共通判定へ加える。
  外部パスのチェック、機械識別子の言語判定除外、切り詰め用途別の修復案は自動チェックで固定する

- 2026年11月15日〜17日: `atk wi process-loop`を、対象ごとの独立した会話、通常起動の非対話CLI、予約のない前回会話の再開へ変える変更が、ユーザー確認なしに実装・公開された。
  ユーザーの発話は「process-loopの処理がどうあるべきかを考え直した方がいい」「process-wiで重要なのは単位時間あたりのWI処理数」であり、会話の分割も端末表示の廃止も求めていなかった。
  直接原因: 改善を広く任せる発話を、ユーザーが現在使っている起動形・表示・既定の動作を変える個々の判断の承認源として扱い、統括の起草・計画担当の手段の選択で、端末で画面を見て入力できなくなる結果を既存の動作と比べなかった。
  影響: dotfilesユーザーが進行を端末で確認・介入できなくなり、ユーザーが4回の是正指示で元の動作へ戻させた。
  対策: 1つの統括会話を前景の対話CLIで起動し、再開を予約時に限る構成へ戻した。
  エージェントが補った結果のうち、エンドユーザーが自分で起動・操作するコマンドや画面の動作を大きく変えるものは保存前に確認し、軽微な利便性の向上と細部の変更はエージェントが確定して報告する。
  守る動作を`docs/development/concepts-environment.md`「実行環境と表示」へ記録した
