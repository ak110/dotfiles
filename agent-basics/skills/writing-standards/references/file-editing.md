# 既存ファイルの編集

本書は既存ファイルを変更するエージェントへ、現行内容を踏まえた編集と結果確認、機械変換の進め方を定める。対象はコード、文書、エージェント向け文書を問わない。改行とBOMの保全は`encoding.md`「書込ツールの改行・BOM保全」が定める。

## ファイル更新時の編集ツールの前提

現行の対象内容と変更の前提を確かめて編集し、終了状態と差分から意図した結果になったことを確認する。委譲した編集も、書き込む担当が自身のホストの前提を満たす。
スクリプトによる置換は入力と一致数も確かめる。

## 複数ファイルの機械変換

スクリプトで複数ファイルを変換する場合は、全入力の読取と前提（対象、一致数など）の確認、全出力の生成と構文チェックを済ませてから製品ファイルへ書き込む。生成結果はメモリーか実行環境が用意した一時領域へ保持し、途中で前提不成立や構文不良を見つけた時点で製品ファイルを元の状態に保てるようにする。
構文が成立しても参照先・呼出側・テストとの意味の整合は保証されないため、書込後に直接影響範囲（`quality-principles.md`「変更と検証の範囲」）を確かめる。
