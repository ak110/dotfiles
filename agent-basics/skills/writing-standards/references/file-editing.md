# 既存ファイルの編集

本書は既存ファイルを変更するエージェントに向けて、現在のファイル内容を踏まえた編集や結果の確認、機械的な一括変換の手順を説明する。対象はコード、一般的なドキュメント、エージェント向け文書のいずれでも共通である。改行コードとBOMの保持ルールは、`encoding.md`の「書込ツールの改行・BOM保全」を参照する。

## ファイル更新時の編集ツールの前提

編集対象の現在内容と変更の前提条件を確認した上で編集を実行し、ツールの終了ステータスと生成された差分から、意図どおりに変更できたことを確認する。編集作業を委譲する場合も、実際に書き込みを担当する側が自身の実行ホストにおける前提条件を満たすようにする。
スクリプトで置換するときは、対象の入力内容と置換の一致件数も併せて確認する。

## 複数ファイルの機械変換

スクリプトを用いて複数のファイルを変換するときは、まずすべての入力ファイルの読み込みと前提条件（対象ファイルや一致件数など）を確認し、出力内容の生成と構文チェックまで完了させてから、本番のファイルへ書き込む。生成途中のデータはメモリー上か実行環境の一時領域に保持し、途中で前提条件の不一致や構文エラーが見つかった場合でも本番ファイルを元の状態のまま保てるようにする。
構文エラーがなくても、参照先や呼び出し側、テストとの意味的な整合性が保たれているとは限らないため、書き込み後には直接影響範囲（`quality-principles.md`の「変更と検証の範囲」）を確認する。
