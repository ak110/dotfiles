# 成果物へ書く事実の調査：仮説から次の確認を選ぶ

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

## 仮説から次の確認を選ぶ

未確定の前提や試行結果によって次の行動が変わる場面では、仮説、識別したい不確実性、最小の確認、観測、採否を対応付ける。
結果を左右する環境・外部条件は確認済みの事実と仮定に分け、重要な仮定を実装全体の前提にする前に、使える公開操作や小さな試作で確かめる。
技術的に確かめられる不確実性は調査で解き、ユーザーだけが決める値と区別する。

仮説が反証されたら、検証済みの成果と有効な方針を保ち、崩れた前提、失敗した案と条件、次の確認を既存の計画・検証記録へ残す。
新しい情報を得ない同じ試行が続く場合は、前提と優先順位を見直し、継続・撤回・別案を選ぶ。
不採用案の理由と再検討条件、取得済みの環境知識は再開時にも再利用する。
永続的に価値のある知見だけを既存の設計・方針・障害記録へ集約し、通常作業への実験追加は次の判断に必要な場合に限る。
