# スライド

短い見出し、体言止め、箇条書きを保ち、読点は論理関係を保つ範囲で整理する。仮の値などに関する依頼者向け注記を残す。
資料の目的、説明順序、各ページで伝える要点を構成段階で定め、要素ごとにその要点を説明する役割を対応付ける（努力目標）。
主となる情報、補足、注記の関係と読む順序を配置で示し、必要な補足は説明する対象との関係が分かる位置へまとめる（努力目標）。
規模、比較・変化、仕組み・手順など、伝えたい関係に合わせて数値、グラフ、図を選ぶ（努力目標）。
図表を単独で読む場合にも、単位、出所、成立条件、見込みと実績の区別を保つ。
作成・改稿したページと影響する範囲を画像で確認し、要点や読む順序が不明瞭な場合は、情報の削除、統合、配置変更を選ぶ（努力目標）。
ブランド、テンプレート、ページ数など、その資料で指定された条件は維持する。
