# 原則8：読み手の文脈で書く

文章は、読み手が持っている知識と、読み手が次に行う判断から書く。
読み手が持たない前提を補い、結論を先に置く。
定義は1か所に置き、他の場所には、そこへ進む条件と所在だけを書く。

## 理由

読み手は、書き手の会話、作業の経過、頭の中の略称を持っていない。
書き手にとって自明な前提が欠けると、読み手は対象を特定できないか、違う対象として読む。
同じ定義が複数の場所にあると、片方だけが改訂されて食い違い、読み手はどちらに従うかを決められない。

## 失敗例

- 会話の中だけで通じる言葉で書いた。
  委譲の依頼文と作業項目の本文に、「先ほどの方針」「例の修正」と、作業中に付けた略称を書いた。
  読み手は別の文脈で読むため、対象を特定できず、質問の往復か誤った作業が起きた。
  対象、目的、完了の条件を、その文章だけで分かるように書く。
- 同じ規定を2か所に書いた。
  ある手順を、最初に読む文書と詳細の文書の両方へ書き、後で詳細の側だけを改訂したため、読んだ場所によって行動が分かれた。
