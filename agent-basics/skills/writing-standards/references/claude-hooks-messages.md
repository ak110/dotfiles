# エージェント宛てメッセージ

本書はhookとhook以外の生成元がエージェントへ直接渡す本文の記述言語、機械生成本文の標識と、hookの通知本文の整形を定める。

## 名指し参照の読込方法

本文の各参照の適用条件を保ち、選んだ資料の指定範囲を取得してから、その基準を使う具体的な判断へ進む。起動時の行の資料は起動本文とともに届く。

| 時点または条件 | 全文読む資料 | 契機 | 配送操作 |
| --- | --- | --- | --- |
| 本文がこの資料の基準を使う場面で、資料を選択して取得する時 | `claude-hooks-block-warn.md` | 判断 | `read:agent-basics:*/skills/writing-standards/references/claude-hooks-block-warn.md` |
| 本文がこの資料の基準を使う場面で、資料を選択して取得する時 | `writing.md#「読み手別の追加注意点」` | 判断 | `section:agent-basics:*/skills/writing-standards/references/writing.md#「読み手別の追加注意点」` |

## メッセージの記述言語

エージェントに直接渡る出力（`reason` / `additionalContext` / exit 2のstderr）は日本語で書く。日本語以外の文が会話へ挿入されると、モデルの以後の発話言語がその言語へ引きずられる。
原本ファイル（`CLAUDE.md`等）の章名・節名・キーワードは、原本の改名に追従できるよう原本表記のまま引用する。

## エージェント宛てメッセージの標識

機械生成本文には、ユーザー自身の発話と区別できる境界、生成元、通知種別を設ける。転載するユーザー入力も別に識別し、機械生成の説明をユーザーの認可と扱わない。エージェントに届かないフィールドと追加本文の無い許可応答は対象外とする。

## 通知本文の整形

本節は遮断・警告・定型通知の本文構成を定める。遮断を`block`、原因への対処を促す警告を`warn`、発話ごとの定型配送を`notice`、解消手段の引数を`fix`と呼ぶ。遮断と警告の選択は`claude-hooks-block-warn.md`に従う。

- 遮断・警告の整形関数は、解消手段を必須の引数として受け取り、空または空白だけの値を拒否して、本文の後へ次の操作を示す
- 遮断・警告は共通の整形関数を通し、本文と解消手段を別の引数で受け取る。文面は`writing.md`「読み手別の追加注意点」に従う
- `notice`区分は行動の指示そのものを本文とする定型の配送であり、`fix`を任意とする

遮断の解除に必要な情報は通知本文へ載せる（別の呼び出しでの取得を求めると遮断のたびに1ラウンドを消費する）。
判定が出力の有無や形式など守る結果の代わりとなる条件だけを調べる場合は、`fix`で守る結果へ到達する操作を名指し、判定に合格する最小の出力と守る結果を区別する。
`fix`の手段を使えないエージェントがある場合は、同じ判定を通過する別の手段か、遮断が解除される条件を併記する。
集合を本文へ列挙する場合は、判定した対象と対応づく要素に限定する（努力目標）。

`warn`区分の通知は、同一セッションで同じ原因が繰り返された時点から、繰り返していることと累積件数を本文へ含め、2件目以降は本文を対象と件数へ縮める。`次の操作:`の行は残す。
