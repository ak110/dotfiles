# 画面の主題別設計

本書は、フォーム、一覧、検索、通知、パネル表示、AI連携、同意・解約フロー、多言語対応などを含む画面の設計、実装、レビューをする際に参照する指針である。
設計にあたっては、まずエンドユーザーの作業の流れと中断可能な範囲を明確にし、各機能における操作から最終結果に至る動線を一貫して確認する。

参考資料: [ux-designer-skill](https://github.com/szilu/ux-designer-skill)、[frontend-ui-ux-skill](https://github.com/overseek944/frontend-ui-ux-skill)。これらの資料をもとに主題別の判断基準を再構成した。アクセシビリティや表示性能に関する基準値は[W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)および[web.dev Core Web Vitals](https://web.dev/articles/vitals/)に準拠し、共通の指標値は`ui-ux.md`にまとめている。

## フォームと入力

入力項目はユーザーが判断しやすい論理的な順序で並べ、必須の有無、入力形式、文字数や値の上限を事前に入力欄の近くで明示する。
バリデーションエラーが発生した場合は該当する入力欄の直近で具体的な原因を伝え、送信時にはフォーム全体を検証してエラー箇所へスムーズに移動できるようにする。
入力内容が失われる可能性がある画面遷移や閉じる操作をする場合は、保存、破棄、または編集継続をユーザーが明示的に選択できるようにする。

## 一覧とデータ表

一覧画面では、各行やカードの対象データと次に実行可能な操作が一目で分かるように設計し、現在の並び順、ページ位置、選択状態を常に明示する。
一括操作を提供する場合は対象となる件数や範囲、実行結果を分かりやすく表示し、詳細画面の閲覧や作業の中断から一覧へ戻った際にも元のスクロール位置やページ位置を維持できるようにする。

## 検索

検索キーワードの入力中に表示するオートコンプリートや候補サジェストでは、各候補を選択したときに何が起きるか（検索の実行か、詳細画面への直接遷移かなど）を明確に示す。
検索結果が0件の場合は直前の検索条件を画面上に維持し、条件の解除や再入力を案内する。
検索対象のデータ自体が存在しない場合は、検索条件によって0件になった状態と区別して表示する。
非同期検索では、直近に入力された最新の検索条件に対応する結果のみを画面に反映する。

## 通知と割り込み

トーストやバナーなどの通知表示は、ユーザーの作業を中断させる必要性の度合いと、後から見返す必要性の度合いに応じて適切な形式を選択する。
エラー通知はユーザーが内容を確認して明示的に閉じるまで表示を保持し、操作の取り消し（Undo）を案内する場合はワンクリックで実行できる手段を提供する。
通知の出現や消失によって既存コンテンツの配置やキーボードフォーカスが不意に乱れないように配慮する。

## モーダル、サイドパネル、全画面表示

モーダルダイアログ、サイドパネル、全画面表示の使い分けは、作業に必要な時間、作業を中断できるかどうか、背景の画面情報を参照しながら進める必要があるかどうかに応じて選定する。
閉じる操作（Escapeキーや閉じるボタン）の提供、未保存の変更がある場合の警告、ダイアログを閉じた後の元の要素へのフォーカス復帰、画面幅が狭い環境でも問題なく操作できることを確認する。

## AIを使う画面

AIによって生成されたコンテンツは、エンドユーザー自身が作成したテキストや確定データと明確に区別して表示し、根拠となる情報源を提示できる場合は確認しやすい位置に配置する。
生成処理の進行状況の明示と中断手段、AIが適用した変更の取り消し機能、ユーザー自身による自由な上書き編集を可能にする。
AIの生成結果が未検証である場合はその事実を明確に伝え、最終的な確定判断を常にユーザー自身が行える操作体系を維持する。

## 同意、拒否、解約

任意の同意事項については、初期状態ではチェックを入れず未選択とする。
同意するボタンと拒否するボタンは同等に見つけやすい配置や配色とし、拒否を選択したユーザーを責めたり引き留めたりする過度な文言を用いない。
解約や退会の手続きは、登録手続きと同程度に容易にアクセスできるように配置し、手続き完了に伴う結果、利用できなくなる機能、および事前に必要なデータのバックアップ手順を実行前に丁寧に説明する。

## 多言語表示

翻訳対象のテキストはコード本体から適切に分離し、翻訳後のテキスト長の変化、文字の表記方向、地域ごとの日付や数値フォーマットの違いが生じても、レイアウトが崩れず操作や情報に到達できるようにする。
固有名詞やプログラムのコード片などは、誤って翻訳されないよう対象から除外する。
