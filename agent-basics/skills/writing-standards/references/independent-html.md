# 単体HTML成果物のスタイル規範

本書は、ブラウザで直接開くだけで完結して閲覧できる単体HTML成果物の実装指針をまとめたものである。

## 適用範囲

対象は、ユーザーへ単体の成果物として提供するHTML（調査レポート、ダッシュボード、データの可視化、プレゼンテーション資料、UIプロトタイプなど）である。
Webシステムの一部として動作するHTML（Webフレームワークのテンプレートファイルやコンポーネントなど）については、本書ではなく、各フレームワークやプロジェクトの規約に従う。

## 実装指針

- 成果物は1つのHTMLファイルにまとめ、別ファイルへの分割は行わない。
- スタイル定義はCDN経由のCSSフレームワーク（`daisyUI`など）に統一し、インラインスタイルの多用を避ける。
- オフライン環境での表示が要件に含まれる場合に限り、CDN経由での読み込みを行わず、必要なCSSやJavaScriptをHTMLファイル内へ直接埋め込む。
- そのファイル単体を開くだけで主要な操作が完結する構成とし、見やすい情報密度と目的の情報へのアクセスのしやすさを両立させる。
- テーマの切り替え機能、ナビゲーション、データのエクスポート機能、編集とプレビューの同時配置などは、成果物の用途に応じて採否を判断し、一律に追加することは避ける。

## 技術選択の指針

標準的なHTML/CSS/JavaScriptで実現できる範囲は独自に実装せず、定評のあるフレームワークをCDN経由で読み込んで活用する。
外部APIへの通信やバックエンドサーバーとの連携が必要な構成は、単体HTML成果物のスコープから外れるため、Webシステム向けの開発規範に従って設計する。
