本書は、Claude Codeの`Edit`ツール、および`Write`ツールによる既存ファイルの上書きに適用する。共通の編集手順や結果確認の手順は、`file-editing.md`を参照する。

## 操作前の読取状態

`Edit`ツールや既存ファイルへの`Write`ツールを実行するには、ホスト環境が対象パスの読み取り状態をあらかじめ保持している必要がある。編集する前に、同じ会話内で対象の絶対パスに対して`Read`ツールを実行し、この読み取り状態を満たすようにする。内容をあらかじめ把握しているかどうかと、ツール実行に必要な読み取り状態が成立しているかどうかは、それぞれ個別に確認する。

なお、次のような操作や取得方法は`Read`ツールの代わりとして扱わない。

- Bashでのファイル内容の表示。読み取り状態が成立するかどうかはコマンドの解析処理に依存し、変数を含むパスやパイプなどで連結したコマンドでは成立しない
- リダイレクトや`cp`、`sed -i`、`iconv`などによるファイルの作成や変更
- 別のパスに対する`Read`、他の担当者から受け取った本文、過去の`Write`結果の参照

複数のファイルに対して`Edit`をまとめて発行する場合は、対象となるすべてのファイルで`Read`が成功した後に実行する。未読を理由に編集が拒否されたときは、対象ファイルを`Read`してから再度実行する。軽量な書き込みを担当するサブエージェントにも、同様の事前条件を適用する。
