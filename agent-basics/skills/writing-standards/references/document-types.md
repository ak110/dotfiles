# 文書の役割と種類

ドキュメントを作成するときは、後から読む読者へ何を伝えるのかを明確にし、「参照用」「作業用」「経緯の記録」という用途から適切なものを選ぶ。ファイル名だけで用途を判断しないようにする。参照用の文書には現在の仕様や使い方を整理して残し、作業中のタスクや進捗状況は作業用の文書で管理する。経緯の記録には、後から当時の判断を検証できるように事実関係を記録しておく。情報をどこに書き分けるかの基準は、`writing.md`の「文章の共通規定」を参照する。

次の表は、想定する読者や役割に応じて文書の種類を選ぶための目安である。各文書の具体的な書式や判定基準の詳細は、それぞれのリンク先にある専用の規定を確認する。

| 文書 | 主な読者と役割 | 伝える内容と詳細規定 |
| --- | --- | --- |
| README | エンドユーザーや開発者が使い始めるための参照用 | 対象読者、実現できること、導入の前提条件、主要な操作方法、および詳細な資料への案内。書き方は`writing.md`を参照する |
| 利用ガイド・運用手順 | エンドユーザーや開発者が操作手順を確認するための参照用 | 主要な操作の前提条件、具体的な手順、期待される実行結果、前提が合わない場合の対応手順。内部仕様とエージェント向けの指示は含めず、分量は`writing.md`「読み手別の追加注意点」の「エンドユーザー向け文章」に従って選別する |
| 構成の説明 | 開発者や保守担当者が全体のアーキテクチャを把握するための参照用 | ディレクトリ配置、各コンポーネントの責務と境界、配布先、主要な連携関係と実装コードとの対応関係 |
| 設計の記録 | 開発者や保守担当者が過去の設計判断の理由を確認するための参照資料 | 制約条件、システム構造、選定理由、採用を見送った代替案と影響。複数の資料に分かれている場合は、目的のトピックを探せる目次を用意する |
| 技術文書（技術記事・設計書・技術解説） | 技術の使い方や仕組みを理解し、手元で再現したい読者向けの参照用 | 入力データ、実行コマンド、設定値、およびその結果。書き方は`writing.md`の「文書種別ごとの注意点」にある「技術文書」を参照する |
| エージェント向け文書 | コーディングエージェントが作業方針を判断するための参照用 | 想定する読み手、適用するタイミング、判断基準、および次に取るべき操作。`agent-documents-basics.md`、`agent-documents-additions.md`、`agent-skills.md`などの該当資料を参照する |
| 方針の由来の記録 | 今後の開発者やエージェントが過去の決定事項の経緯を調べるための記録 | 決定した内容と当時の背景、およびその判断が現在のどの規範に適用されているかの関係 |
| 障害の記録 | 今後の開発者やエージェントが再発防止に役立てるための記録 | 観測された事象、直接の原因、講じた対策、および発生条件 |
| 検証記録 | 今後の開発者やエージェントが過去の技術判断を再検証するための記録 | 観測時の前提条件、得られた結果、再検証の手順、およびその結果を前提とした判断内容 |
| 計画ファイル | 作業の実行担当者が変更を着実に進めるための作業用 | 要件、変更内容、検証手順、作業完了条件と進捗状況の対応関係 |
| コミットメッセージ | 開発者が変更の目的をGitの履歴から追跡するための記録 | 何をなぜ変更したのかを、明確な件名と必要な補足本文で記述する |
| 業務・仕様文書（仕様書・業務報告・提案書） | 読者が意思決定や行動に移るための連絡・参照用 | 意思決定する主体、条件と結果、採否の判断基準。書き方は`writing.md`の「文書種別ごとの注意点」にある「業務・仕様文書」を参照する |
| PR・MRの説明 | レビュアーや関係者にレビューを依頼するための連絡文書 | 変更の目的、得られる成果や挙動の変化、および確認済みの検証範囲。書き方は`writing.md`の「文書種別ごとの注意点」にある「業務・仕様文書」を参照する |
| Release本文 | エンドユーザーや開発者へ配布された変更内容を伝える記録 | エンドユーザーへ届く機能変更や修正内容、必要な操作手順や注意事項 |
| 体験を述べる文章（エッセイ・体験記・個人ブログ） | 本人の実体験や感想を読者に伝えるための文章 | 本人が経験した状況、受けた印象、感想、および得られた知見。書き方は`writing.md`の「文書種別ごとの注意点」にある「体験を述べる文章」を参照する |

## 名指し参照の読込方法

名指し参照は`../SKILL.md`「名指し参照の読込方法」に従う。

| 時点または条件 | 全文読む資料 | 契機 | 配送操作 |
| --- | --- | --- | --- |
| 本文がこの資料の基準を使う場面で、資料を選択して取得する時 | `writing.md#「文章の共通規定」` | 判断 | `section:agent-basics:*/skills/writing-standards/references/writing.md#「文章の共通規定」` |
