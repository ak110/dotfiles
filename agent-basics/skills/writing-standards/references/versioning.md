# バージョン番号の付け方と読み方

配布物のバージョンを決める担当と互換性を判断する担当が、番号の意味を思い込まず、利用者に実際の変更を伝えられるようにする。

- SemVerはバージョン付けの方式の1つであり、従わないOSSも多い。
  バージョン番号の付け方や読み方でSemVerを既定にしない。
- 自分のプロジェクトでは明示された方針に従い、方針がなければ過去のリリースの慣行に合わせる。
  互換性を壊すという理由だけで、メジャーバージョンへの変更を提案したり、レビューで指摘したりしない。
- 依存先の互換性は、メジャー番号が変わらないことだけでは判断せず、リリースノートと実行で確かめる。
- SemVerの基準を適用するのは、対象プロジェクトがSemVerを採用すると明示している場合に限る。
