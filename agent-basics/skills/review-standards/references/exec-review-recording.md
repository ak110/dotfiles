# 判定根拠の品質

要求ごとに原文と出所、判定、直接必要な観測と適用理由、確認した版を対応付ける。原文を保持し、失効した説明と別要求の経緯は現在の根拠へ置き換える。複数要求が同じ記録を使う場合も該当する観測を個別に確かめる。
過去の観測を再利用する場合は、取得時の版と条件を読み、対象・依存・入力・環境のうち結果へ作用する条件の同一性を確認する。祖先関係や差分の見た目だけで同一とせず、確認できない範囲を証拠不足とする。履歴自体を試す検証は取り直す。
受理済みの判定も、今回の変更で結果へ作用する内容・条件が同じ行だけ参照する。必要な根拠へ再到達できる参照と適用理由を残し、参照できない場合は今回の観測へ戻る。
根拠は原文の要求単位を過不足なく覆うことを読み手が確かめる。最低行数や成功件数だけを充足の根拠にしない。指摘の成立と判定基準は`reviewer.md`、採否と修正は`reviewee.md`による。

## 名指し参照の読込方法

本文の各参照の適用条件を保ち、選んだ資料の指定範囲を取得してから、その基準を使う具体的な判断へ進む。起動時の行の資料は起動本文とともに届く。
