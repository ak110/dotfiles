# 判断の妥当性を評価する詳細：既存記述との重複と方針との整合

## 名指し参照の読込方法

名指し参照は`agent-basics:writing-standards/references/read-method.md`に従う。

| 時点または条件 | 全文読む資料 |
| --- | --- |
| 本文の参照基準を適用する前 | `../../bugfix/references/root-cause-prevention-requirements.md` |
| 経験を保存・再利用する案を点検する前 | `../../writing-standards/references/investigation-experience.md` |
| 本文がこの資料の基準を使う場面で、資料を選択して取得する時 | `../../writing-standards/references/design-heuristics-proportionality.md` |

## 既存記述との重複と方針との整合

規範、ドキュメント、または設定へ新しく記述を追加する案を検討するときは、追加先で同じ判断基準がすでに成り立っていないかを確認する。
既存の記述を補強するだけで目的を果たせる場合は、新規追加ではなく補強を採用する。
変更を確定する前に、明文化された既存の方針と整合しているかを照らし合わせる。
外部資料との比較では、`../../writing-standards/references/design-heuristics-proportionality.md`「問題と手段の比例性」に従い、意味上の被覆と実効性の根拠を独立に検収する。
条文の対応表だけから十分性を認めず、未確認の範囲が採否でどう扱われているかも確認する。
既存規範への違反を是正する場合は、本節の重複回避ルールを適用しない。
`../../bugfix/references/root-cause-prevention-requirements.md`「再発防止策の必須性」にある未適用規範の是正原則に従って対処する。
