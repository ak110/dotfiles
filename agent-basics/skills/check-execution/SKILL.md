# formatter・linter・testerの実行

本スキルはformatter、linter、testerおよびプロジェクト固有のチェックツールを起動するエージェントへ、起動手段の選び方を提供する。
各ツールの受理形式と出力形式は、そのツールのヘルプ、MCPツールのスキーマ、公式ドキュメントに従う。

チェックを動かすには対象の実行環境とCLIかチェック用MCP、保存結果を判定するにはその記録の読取手段が必要である。実行手段が無い場合は、提示された保存結果の判定と検証対象・コマンドの選定までを行い、未実行のチェックを明示する。新しい検証と実行記録の保存は、対象を実行できる実行環境で行う。結果の説明には[文章の品質基準](references/quality-standards.md)を使う。

QCD、3段判定、事実と推論、硬い制約と努力目標は`agent-basics:writing-standards`の`references/quality-principles.md`が定義する。

## 名指し参照の読込方法

本文の各参照の適用条件を保ち、選んだ資料の指定範囲を取得してから、その基準を使う具体的な判断へ進む。起動時の行の資料は起動本文とともに届く。

## 実行条件と結果

各チェックはプロジェクトが採用する実行形と公開された入力契約に従う。保存結果を読む前に、用途に合う出力形式と対象を生成元の公開指定から選ぶ。本文表示と構造化した診断・要求への関連付けは用途を分け、結果と取得条件の一致を確認する。実行・保存の機能が無い場合は検証対象と手順、未実行の範囲を返す。
