# 外部資料の取得

外部資料を調査の根拠として取得する時の、資料ごとの手順を扱う。
取得した内容を事実主張や引用に使う基準は`agent-basics:writing-standards/references/investigation.md`に従う。
取得手段が無い環境では、対象の同定と手順を整理して返し、取得していない本文は未取得として扱う。

| 時点または条件 | 全文読む資料 |
| --- | --- |
| Xの投稿本文・日時・添付写真を取得する前 | `agent-basics:fetch-sources/references/x-posts.md` |

## Webページの本文の取得

シェルからWebページの本文を読む時は、`uvx pytilpack fetch <URL>`を基本にし、標準出力を一時領域のファイルへ保存して使う。
このコマンドは、HTMLからヘッダーやナビゲーションなどを除き空白を詰めた本文のHTMLを要約せずに出し、JSONの応答はそのまま出す。
HTTPのエラーでは状態コードを含む診断を出して終了コード1を返し、その診断で取得の成否を判断する。
扱わない形式の応答（`text/csv`など）でも終了コード1を返す。
次の場合は`curl`を使う。

- 逐語の引用の原本にする場合（加工されていない生データを保存する）。
- 扱わない形式の応答。
- 画像などのバイナリの保存、HTTPステータスやリダイレクト先の確認、認証ヘッダーやメソッドの指定が要るAPIの呼び出し。
- `uvx`が無い環境。

## 取得を委譲する時

1. 委譲の依頼文へ、資料の種別に応じた手順を含める。
   X投稿なら`references/x-posts.md`の絶対パスと、FxTwitter APIを使うことを書く。
2. 委譲先が取得失敗を返した資料は、成果物の根拠・参考資料に使う前に、同じ手順を自分で試す。
3. 試した後も取得できない資料は「未取得」として扱い、根拠や参考資料の位置へ置かない。
