# 秘匿値ファイルの取り扱い

作業ツリー外の秘匿値ファイルの読み取りと、作業ツリー外の通常ファイルからの秘匿値の検索で、値を出力・複製しない保護を定める。
値の出力は取り消せない（トランスクリプトやログに残る）ため、`agent-basics:writing-standards/references/quality-principles-constraints.md`（取り消せないことの前で止まる）の適用である。

## 適用範囲

作業ツリー内のファイルは、追跡の有無、gitignore、ファイル名（`.env`、鍵、証明書を含む）にかかわらず通常のファイルとして扱い、本スキルを適用しない。
作業ツリー内から外部の認証情報を参照する場合は、認証情報の実体の場所で内外を判定する。
ファイル操作が無い環境では、値の提示や複製を求めず、必要なキー名と、値を出さずに確かめる方法を案内する。

## 秘匿値ファイルの読取

作業ツリー外の秘匿値ファイル（`.env`、`.env.<接尾辞>`、鍵、証明書など）は、必要なキーの値だけを取り出す操作で読む。
全文の読み取りと、画面・ログへの出力はしない。
ホーム配下の認証情報を複製・移動・別領域へ保存しない。

## 秘匿値の検索

作業ツリー外の通常ファイル（ログ、設定、スクリプト、Gitの履歴など）から、秘匿情報らしい値の有無、件数、所在、同一性を調べる時は、一致した値が出力される形式を避ける。
避ける形式は、`grep -o`、オプションなしの`git grep`と`rg`による一致行の表示、`git log -p`と`git show`の差分表示である。
有無と所在はファイル名一覧（`-l`）か件数（`-c`）、同一性と重複は値ごとのハッシュの比較で判定する。

```sh
rg -o -N --no-filename '<パターン>' <パス> | while IFS= read -r v; do printf '%s' "$v" | sha256sum; done
```

値を出す検索の後段に`grep -v`や`sed`をつないで値を除くパイプラインは使わない。
前段の出力形式やホスト設定で1度でも除去に失敗すると、値が記録に残って取り消せない。

## 値を見つけた時の報告

`agent-basics:writing-standards/references/quality-principles-constraints.md`「秘匿値」に該当する値をGit管理外で見つけた場合だけ、所在を報告する。
