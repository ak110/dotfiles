# 原因分析の記録の品質

分析には事象・発生条件・実際値、期待する契約、直接的原因と根拠、対策、類似見直しの観点と結果、再発防止策を残す。QとC・Dの区別、重大度と根拠、母集団、是正・予防対象、探索の限界と残存リスク、各処置の根本原因への作用と完了の観測を対応付ける。数値は生成元と条件の一致する比較群を確かめ、不確定な値は推定として区別する。
拡張原因分析では`causal-analysis.md`の2系統・L1〜L4を記録し、到達しない段は該当なしの根拠、資料不足は未確認として区別する。判断過程と比較の詳細は再取得できる証拠に残し、結論と所在を本文へ書く。
複数の観測事象を1つのバグ単位へ統合するのは、直接的原因と対策の変更単位がともに同じ場合だけとする。根本原因が共通でも直接的原因が異なれば分ける。バグ単位を分けても同じ根本原因の類似見直しと再発防止の完了は全件で判定する。

再発防止策を採用する記録には、`root-cause-analysis.md`「処置の階層」の持ち込みの試験に使った形の異なる問題を1件以上（対象の所在か将来の追加の形）と、処置が混入を防ぐか検出する理由を書く。観測した箇所の回帰テストは対策へ記録する。採用しない場合は、その結論と終了根拠を同じ記録へ残す。
