# 類似見直しの範囲と探索

類似見直しを担当するエージェントが、根本原因から母集団と観点を導き、是正対象と予防対象を調べる。
調査の深度と限界は確定した重大度に合わせる。

## 類似見直し

類似見直しとは、今回の問題と根本原因を同じくする独立した不具合や潜在欠陥を、現れ方の違いにかかわらず洗い出す活動である。
元の不具合の原因分析と修正影響の調査は、必要な追随修正の範囲を確定する活動として区別し、元の事象への寄与が判明した対象は元の原因分析と修正範囲へ戻す。
原因分析後、具体的な処置を選定する前に、重大度によらず次の絞り込み型の手順を行う。
作り込み・見逃しの各系統で観点の候補を1件以上作り、各観点に原因条件から導く対象と探す問題を示して、採否と理由を記録する。
確定、仮説、未確認、該当なしは区別し、該当なしの基準は`causal-analysis.md`「原因分析の段階」に従う。
仮説は支持する事実、不確実性、因果の見込み、実施結果を対応付ける。
真偽によって採る対策が変わる仮説を検証しないまま分析を終える場合は、次のどちらかを選ぶ。
採否を左右しない仮説は記録だけで終えてよい。
これは、その場で調査できない事象を後続の作業項目へ先送りする扱いの適用であり、未検証であることを対策を立てない理由にしない。

- その場の費用で検証できるなら検証し、結果を記録する
- 検証用の後続の作業項目を登録する。
  本文には仮説、支持する事実、検証方法、支持・反証・判定不能ごとの処置を書き、待機の要否と期限・依存は利用側の作業項目の手順に従う

1. 根本原因から、破られた不変条件または誤った判断規則を1文で定め、母集団と該当・保留・非該当の判定基準を選ぶ。
   標準の母集団は対象リポジトリのGit管理下のファイル、直近7日間の作業項目、直近7日間のセッションログとし、根本原因が他の範囲に及ぶ場合だけ追加する。
   現存ファイルは更新日で除外せず検索し、履歴を遡る範囲は追加調査も含め見直し開始時点から直近7日間とする。
   期間外の履歴は調査対象外・処置未確認として記録する。
2. 母集団をgrepなどで検索し、各段の検索式と件数を記録する。
   件数が多すぎる場合は別の条件を足し、十分に絞れた候補だけを本文で個別に判定する。
3. 候補を該当・保留・非該当へ分け、現物と判定基準から根拠を示す。
   原因条件から導いた集合を判定の基準に保ち、対象の除外は現物と原因条件の不一致に基づいて決める。
   別リポジトリへの追加は、実際の利用条件の成立を確認できた範囲に限る。
4. 該当が0件なら、原因の抽象度、時間軸、参照・利用関係、異なる現れ方などから別の語や観点の検索式で1回見直す。
   その結果も0件なら、検索範囲・限界と判定根拠を残して終了する。

同じ規則で母集団全体を機械検査するツールの全体実行は、その規則の類似見直しとして扱ってよい。
その場合も、ツール対象外の文書・設定・生成物などに同じ原因の誤りがないかを絞り込み型で調べる。
検索文字列に一致しない消費側の全件確認や、現存ファイルすべての本文精査は一律に課さず、検索結果から候補を選ぶ。
重大度は母集団の広さと個別判定の深さへ反映し、調査範囲・限界・許容する残存リスクを記録する。

### 起点の問題を伏せた走査

重大な問題では、起点の詳細を知らない独立した担当へ走査を依頼して検出を確かめる。
判定規則・母集団・判定基準による読取専用の走査を分担する場合は、起点の具体的な事象・場所・修正内容を渡さず、原因分析と結果の採否は依頼元が所有する。
起点の検出を確かめる場合は問題を含む修正前の版を走査対象にし、依頼元が返却結果と起点を比較する。
未検出なら母集団から漏れたか非該当とされたかを分け、検索条件を1回修正して再依頼する。
再依頼後も未検出なら限界として記録し、担当を増やして検出まで反復しない。
実行環境が専用の担当や検索手段を定める場合は、その起動・受領契約を利用する。

結果は、同じ誤りの仕組みを現に持つ「是正対象」と、将来の追加・変更で混入しうる「予防対象」に分ける。
規範・実装・テストの組合せによる矛盾も、原因条件に沿って判定する。
後続の実装・検収担当が使う母集団、修正・予防の対象、完了の結論と証拠の参照先を本文へ記し、検索各段・分類・除外根拠は既存の分析記録へ残す。
完了は`root-cause-prevention-verification.md`「類似見直しと再発防止の完了」に従う。
担当範囲・認可の外の対象は事象、原因、修正対象、修正方針を依頼元へ返す。
独立した別件は具体化して後続作業へ渡し、引き継ぎ先と処置状況を元の記録へ残す。
元の事象への寄与が未確認の潜在欠陥は、寄与を確認できた場合か同時対応の明示合意がある場合に同じ変更計画へ含める。
